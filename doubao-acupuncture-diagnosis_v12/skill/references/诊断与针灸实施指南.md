# 诊断与针灸实施指南

> 本指南基于《人纪系列·针灸篇》（倪海厦授课实录校勘电子版）整理，将全书针灸知识重新组织为**从病人进门到治疗结束的可执行临床流程方法论**。独立自足，不依赖其他文档。
>
> **两条使用路径**：
> - **初学者系统学习**：按 第一～九篇 顺序通读，每篇理解"为什么这样做"的原理，再对照流程操作。
> - **有基础者实操速查**：直接跳到对应篇目的判断清单、对照表、速查表，按步骤执行。
>
> **四个贯穿始终的前提**：
> 1. 针灸篇默认**不把脉**，诊断以**望、闻、问 + 触诊按压 + 倪师特色观察信号**为主；书中保留的少数脉位（太溪、冲阳、太冲、合谷、人迎）只作"脏气存亡"判断用，不作常规脉诊。
> 2. 全程围绕 **八纲辨证（阴阳·表里·虚实·寒热）** 推进，所有决策都从"虚实寒热"出发。
> 3. 每个判断点通常有**多个可行方案**（如病在时间取俞穴或荣穴），指南会把各方案的原理一并给出，供按需选择。
> 4. 安全与禁忌**嵌入每一步对应位置**，末尾另设总表查漏。

## 第一篇 全流程框架（总览）

治疗全程可拆为 **9 个环节**，每个环节有"输入 → 处理 → 产出"：

| 环节 | 做什么 | 判断/产出 | 对应本篇 |
|---|---|---|---|
| ① 接诊与问诊 | 安定病人，按清单问诊 | 初判病位、病久、寒热、禁忌初筛 | 第二篇 |
| ② 望诊观察 | 眼、舌、指纹、面、色、形、脚 | 确定病脏、虚实、寒热线索 | 第三篇 |
| ③ 触诊按压 | 阿是、背俞、腹诊、特定穴压痛 | 精确定病位、虚实、确认诊断 | 第四篇 |
| ④ 辨证定案 | 汇总①-③，定阴阳表里虚实寒热 | 得出"何脏/何经 + 何虚实 + 何寒热" | 第五篇 |
| ⑤ 选经 | 辨病经，定本经 | 锁定一条（或几条）病经 | 第六篇·一 |
| ⑥ 选穴 | 定虚实→子母补泻；五输穴规则；配穴法则 | 确定取穴方案（可多套） | 第六篇·二~四 |
| ⑦ 下针实施 | 检查禁忌、取体位、找穴、进针、引气 | 针入、气至 | 第七篇 |
| ⑧ 补泻操作 | 按虚实选择补泻手法并施术 | 完成补或泻 | 第七篇 |
| ⑨ 观察与收尾 | 留针、观察反应、起针、交代禁忌 | 判断疗效、安排疗程、结束 | 第八篇 |

> **流程图**：本篇配套一张可视化总流程图（HTML），见交付文件的流程页面；把上述 9 环节和每环节的决策分支画成一条可沿箭头走到底的路径。

## 第二篇 接诊与问诊（闻）

### 2.1 接诊姿态（先决条件）
- 让病人**坐下或躺下**，安定情绪再开始；急症除外。
- 先处理最紧迫问题：若病人**昏迷、剧痛、喘急不能答话**，先急救/先定喘（见第七、八篇应急处理），再行问诊。

### 2.2 问诊清单（可勾选）
按顺序逐项询问，每项都要落到"可判断"的程度：

- [ ] **① 主诉与部位**：哪里不舒服？能否指认具体位置？能否归到某条经络（见第六篇辨经）？
- [ ] **② 病程多久**：痛几天？几个月？几年？（虚实关键）
- [ ] **③ 痛的性质**：是"痛"还是"酸"？是"麻"？拒按还是喜按？
- [ ] **④ 寒热**：喜欢喝冷还是热饮？怕冷还是怕热？身体/手脚温度？
- [ ] **⑤ 饮食胃口**：有没有胃口？能吃多少？饭前饭后胀不胀？
- [ ] **⑥ 渴与饮水**：渴不渴？渴饮多少？喝多是否不解渴？
- [ ] **⑦ 睡眠**：几点入睡？**夜里几点会醒**？（时辰辨证，见 5.5）
- [ ] **⑧ 二便**：大便几天一次？小便颜色？（寒热、便秘部位关键）
- [ ] **⑨ 汗**：出汗情况？汗多部位？
- [ ] **⑩ 妇女经带**：月经周期、颜色、经前乳房胀否、白带色味。（见 5.5、附录）
- [ ] **⑪ 其他诱因**：受伤史、受风寒史、情绪、饮食不节史。

### 2.3 问诊判断信号（对照表）

| 问得的信息 | 推断 | 取穴方向 |
|---|---|---|
| 痛、一周内 | 实症 | 泻子穴 |
| 痛多酸少（七痛三酸） | 实中带虚 | 先泻后补 |
| 酸多痛少 | 虚中带实 | 先补后泻 |
| 只酸不痛 | 虚症 | 补母穴 |
| 麻（麻木） | 最虚、最难治 | 补，疗程长，宜早治 |
| 夜里某时辰准时醒 | 该时辰当令之脏病 | 见 5.5 时辰表 |
| 整天不睡 | 心脏（心神不守） | 心经 |
| 三点到五点醒 | 肺病 | 肺经 |
| 一点到三点醒 | 肝病 | 肝经 |
| 十一点到一点醒 | 胆病 | 胆经 |
| 喜欢喝热饮、脸青、不渴 | 胃寒/里寒 | 灸（中脘、足三里） |
| 口渴饮冷、舌红苔黄、面赤 | 热症 | 针、泻 |
| 大便秘结、小便清白 | 寒实（无蠕动） | 灸天枢 |
| 大便秘结、小便黄、天枢压痛 | 热实（燥矢） | 针天枢、支沟照海 |
| 出汗过多 | 津液伤、小便少 | 少灸（多汗处禁灸） |

### 2.4 问诊即知的下针禁忌（第一道安全门）
以下情形**当下不下针**（可用灸法或改日再治）：
- [ ] 气血大虚、重病、刚失血过多、病人完全无元气
- [ ] 刚行房事后
- [ ] 运动过后、大汗之后
- [ ] 饮酒之后
- [ ] 体力不够

> **原理**：针刺调动经气；在上述状态下经气已虚乱，强行下针徒耗正气。灸法可在针力不足或气血大虚时使用。

## 第三篇 望诊（倪师特色观察信号——核心）

望诊是针灸诊断的第一大支柱。倪师特色的观察信号需**系统编排、逐项核对**。每个信号都指向"何脏病、何虚实、何寒热"。

### 3.1 眼诊（五脏分区）

**分区**：以瞳孔为中心——

| 眼区 | 属 | 查什么 | 异常信号→推断 |
|---|---|---|---|
| 眼白（巩膜） | 肺 | 有无白块、血丝 | 白块如面包屑→肺癌（配夜三点醒）；血丝见下 |
| 内眦（眼内角） | 心 | 颜色 | 赤红 |
| 瞳孔 | 肾 | 对光反应、大小 | 见下 |
| 瞳孔外圈一圈密纹 | 脾/胰（土） | 纹路 | 占约 1/3 |
| 再外一片木纹 | 肝（木） | 纹路 | 占约 2/3 |

**瞳孔对光反应（查肾阳）**：
- 正常：遇光即缩（阳来阴退）
- 光照不动：肾阳已虚
- 瞳孔散大无光：肾气绝（危）

**眼袋下为肾位**：暗黑→肾病；隆起如卧蚕→水肿；暗红→水克火。

**癫、痫、狂眼诊（验治）**：
- 血丝在眼珠上如鸡脚、三缕串至黑珠→最好治
- 黑珠上下均有血丝→难治
- 血丝在下面→不治（仍须尽力）
- 左、右眼同法；**治好标准为"鸡脚"状血丝消失**（用于疗效判断）

### 3.2 舌诊与口腔
- **舌系带旁两条青筋（金津、玉液）**：舌肿大不能翻、讲话不清（木舌症）→点刺出血舌即软；金津玉液放血可去旧血生新血（舌癌、舌肿常用）。
- 舌苔：白厚→寒；黄湿→热。
- 口中味：金属味/甜/苦等异常→治合穴（味主秋）。

### 3.3 指纹诊（小儿，三关辨证）
**看食指掌侧络脉（青筋），分三关**（靠身体为风关，次为气关，到指尖为命关）：
- 青筋现于**风关**：病浅在表，易治
- 至**气关**：病重（入腑）
- 至**命关**：危（入脏）——但至命关**不可弃治**，仍当竭力图救
- 三关青筋黑线在上面两指好治，在下面指头难治

### 3.4 面部五色辨证
| 面色 | 主脏 | 推断 | 取穴 |
|---|---|---|---|
| 青 | 肝 | 肝病（肝虚则青色营养上泛于面） | 肝经 |
| 赤/红 | 心 | 心实（营养受阻上泛于面，两颧赤） | 心经 |
| 黄 | 脾 | 脾病（或肝木克脾土） | 脾经、强土 |
| 白 | 肺 | 肺虚/气血不足 | 肺经 |
| 黑 | 肾 | 肾病（须辨正常之黑与病黑） | 肾经 |

- **手掌颜色候肚脐以上**：正常粉红（肺白+心红）。手掌暗红→肝病（肝实血返心，红增白不变）。掌心赤红壮热→心实；苍白无华→心虚。
- **人中**：消渴饮水无度、面肿→水沟（人中）；人中平者无子。
- **脸赤=胃热，脸苍白=胃寒**；胖人多热、瘦人多寒。

### 3.5 形体、毛发、指甲
- **脚温脚冷（寒热总纲，最重要）**：手脚温热=心脏好、气血能达四肢末梢；脚冰冷=心热不够移热小肠、有血块之虞。**头面身体凉、手足温=正常**（阴阳平衡）。
- **眉毛**：由肺脏管；剃后不易长。寿老者眉毛渐长，为长寿之征。
- **头发**：发乌黑光泽=肾气旺；发蓬起枯白不反光、临死前二三日肾气绝。
- **指甲**（结合）：色、形态可佐证血分。

### 3.6 动态观察信号（贯穿全程）
- **病进**：由**四肢末梢往身上走**（如手伤口红肿一路向上）——表示处方/穴道错了，须重议。
- **病退**：由**身上往四肢走**（如原病在肩，次日肩不痛但痛到手臂）——表示对了，**处方与穴道不能改**，等病好为止。

### 3.7 中风预兆（望诊预警）
- 手前三指麻木→约 6 个月内中风
- 足阳明胃经足三里、上巨虚、下巨虚、丰隆处麻木→约 2 周内中风；见麻木即灸足三里，灸至不麻（可起水泡），连灸数壮。

## 第四篇 触诊与按压（切·按）

针灸篇虽不把脉，但保留**脉位存亡判断**和**按压诊断**两大工具。

### 4.1 可用的脉位（只作"脏气存亡"判断，不作常规脉诊）
- **太溪脉**（内踝高骨与脚后大筋中间，有动脉跳动）：候**肾气**。昏厥者太溪脉存则肾气在、可救；脉无则危。配冲阳脉候胃气、瞳孔候肾气。
- **冲阳脉**（足背解溪下约二寸，动脉搏动处）：候**胃气**。遇不能言之患者，摸冲阳脉可知胃气存亡。
- **太冲脉**（足背行间上一寸）：候**血**（肝）。
- **合谷脉**（合谷穴）：候**气**。临产时合谷脉应手一路跃至食指=真阵痛将产；只痛而脉不起=假阵痛。
- **人迎脉**（颈侧大筋前缘喉结旁）：候**胃气**。人迎脉存则胃气尚存，病可治。
- **脚上三脉总诀**：太冲（血）、冲阳（胃气）、太溪（肾）——**有脉则生，无脉则死**。

### 4.2 阿是穴诊断法（倪师特色核心）
- 阿是**不是**"哪边痛扎哪边"（大陆式误用）；而是在**本经穴位附近寻找最明显压痛点**以定位病所。
- 方法：先辨病经，在该经上按压找最痛点，随压痛移动取穴（如痔疮之孔最或在二寸半、三寸半处；胆结石之阳陵泉下一寸胆石点）。
- **真正阿是**：在肝经经过处找压痛点（治肝三穴），而非笼统"哪痛扎哪"。

### 4.3 背俞压痛法（脏腑定位·核心）
令病人俯卧，沿椎旁（外开一寸半膀胱经背俞）逐椎按压找最痛点：

| 椎位 | 背俞 | 压痛→推断 | 用途 |
|---|---|---|---|
| 第三椎 | 身柱/肺俞 | 肺病 | 诊断+疗效 |
| 第五椎 | 心俞 | 心脏病（闷痛=心虚，刺痛=瘀堵）；红斑性狼疮 | 诊断+疗效 |
| 第六椎 | 督俞 | 血癌（白血球过高、营养过剩） | 治到无压痛即愈 |
| 第七椎 | 膈俞（血会） | 血病（贫血、瘀血、出血） | 血会 |
| 第九椎 | 肝俞 | 肝病（积聚痞痛） | 诊断+疗效 |
| 第十椎 | 胆俞 | 胆病/胆结石（夜十一点到一点难过） | 诊断+疗效 |
| 第十四椎 | 肾俞 | 肾病 | 诊断+疗效 |

> 其他：大杼（骨会，第七椎旁外开一寸半）压痛→骨裂/骨病；压痛消失→骨愈。消渴穴（第八椎下）压之不痛即糖尿病愈。

### 4.4 腹诊
- **瘀血压痛点**：关元外开三、四寸骨旁有压痛→腹中瘀血；人身左侧主血、右侧主气，**子宫腹腔瘀血多在左腹压痛**；腹正中痛多为瘀块、肿瘤。
- **天枢验宿便**：按压天枢，病人惨叫→燥矢堵大肠；压之已软→便已下（疗效判断）。
- **便秘部位**：天枢压痛=燥矢在大肠（热实）；天枢不痛、放屁多=宿食在小肠（小肠便秘，取小肠募关元）。

### 4.5 特定穴压痛诊断（速查）

| 穴 | 按压结果 | 推断 |
|---|---|---|
| 阑尾穴（足三里下一寸） | 显著压痛 | 盲肠炎（男左女右伸腿按） |
| 胆石点（阳陵泉下一寸） | 剧痛 | 胆结石（治到不痛即排出） |
| 肾结石点（太溪上一至二寸） | 压痛点 | 肾结石 |
| 消积穴（足跟大筋上三寸） | 单侧压痛 | 身上有积/肿瘤（治后不痛即愈） |
| 痞根（十三椎外三寸半） | 压痛 | 痞块/肿瘤有根 |
| 百虫窝（血海下一寸） | 压痛 | 腹内有虫（治到不痛为愈） |
| 三阴交 | 按之痛甚 | 痛经甚；治后痛减=瘀血化 |
| 大杼 | 大叫 | 骨裂/骨病 |
| 耳穴压痛点（探针/圆头筷子找阿是，耳如倒置胎儿分区） | 对应区压痛 | 对应脏腑病；消毒后埋图钉样耳针、胶布固定，留 4–7 天（心脏病埋"心的压痛点"6 天，保证不发心脏病） |

### 4.6 虚实按压法（通用）
- **拒按=实**（痛而拒按，喜按=虚）。
- 实者拒按、虚者喜按是辨虚实的快捷准绳，贯穿所有部位。

## 第五篇 辨证框架（分析判断）

把问诊、望诊、触诊所得汇总，落到一个明确结论：**何脏/何经 + 何虚实 + 何寒热**。

### 5.1 八纲总纲
- **阴阳**：脏为阴、腑为阳；里为阴、表为阳；虚为阴、实为阳；寒为阴、热为阳。
- **表里**：病在皮毛、络→表；病在脏、腑深→里。皮毛肺、肌肉脾、血脉心、骨肾。
- **虚实**（见下）。
- **寒热**（见下）。

### 5.2 虚实辨证（决策第一入口）
**判定路径**（按时间+性质+按压三重互证）：
1. 约一周内=**纯实**（痛而拒按）→泻
2. 逾一周=**实中带虚**（痛多酸少）→先泻后补
3. 再久=**虚中带实**（酸多痛少）→先补后泻
4. **纯虚**=不痛但酸→补
5. **麻**=最虚最难治，纯补、疗程长，宜早治

> 补泻方向总诀：**实泻子穴、虚补母穴**；虚实夹杂先泻后补（痛多）或先补后泻（酸多）。

### 5.3 寒热辨证（判断清单）

| 维度 | 寒 | 热 |
|---|---|---|
| 小便 | 清白清淡 | 鲜红/黄赤 |
| 舌苔 | 白厚 | 黄湿 |
| 口渴 | 不渴 | 渴饮冷 |
| 面色 | 苍白 | 赤 |
| 喜热/冷 | 喜热饮 | 喜冷饮 |
| 大便 | 寒实：一周不大便亦不难过（无蠕动） | 热实：一两天不便即腹绞痛 |
| 灸/针 | 寒症用灸（隔姜灸） | 热症用针（灸反助火） |

- **里寒证**：用灸去里寒、用针去血管堵塞（关元等）。
- **灸法适应证**：除虫蛇咬伤外，灸多用于寒症；一般热症不用灸（感冒发烧、多汗处、眼睛、阴部、痔疮热均禁灸）。

### 5.4 五行生克与治未病（决定"治一脏还要防另一脏"）
- 相生=正常；相克传变=病（心→肺→肝→肾→心，克则越坏）。
- **上工治未病**：发现肝病先**强土（脾）**防传变；肺病先强肝；肾病先强心；心病先强肺。
- 正治法：脏病先强**其所胜之脏**（肺病先治肝、再治脾）。
- 缓治法：肝木病先强土（临泣、太白、足三里、灸足三里），再壮水（行间、二间金生水）。
- 急治法：肝硬块积水先疏木（下行间、二间清肺排水），同时强土保胃气。
- **五行五色**：青肝、赤心、黄脾、白肺、黑肾；五味酸入肝、苦入心、甘入脾、辛入肺、咸入肾。

### 5.6 脏象主官（用于理解病机）
- 肺=相傅之官（治节出焉），主皮毛、开窍鼻、藏魄、主忧。
- 心=君主之官，本身不受病，病在心包；藏神、主汗、主喜。
- 脾=谏议之官，主肌肉四肢少腹、统血、开窍口唇、主思。
- 肝=将军之官，开窍目、主筋、藏魂、主怒。
- 肾=作强之官，主骨、藏志、其华在发、开窍耳、主记忆、主二便。
- 胆=中正之官、清净之腑；胃=仓廪之官、肾之关；小肠=受盛之官、赤肠；大肠=传导之官、白肠；膀胱=州都之官、黑肠；三焦=决渎之官、油网。

## 第六篇 选经选穴决策（通用决策规则）

这是指南的核心决策层。**按顺序走四步：辨经 → 定虚实选子母 → 五输穴规则 → 配穴法则**。每一步都给出多方案与原理。

### 6.1 第一步：辨病经

**路径 A｜循行定位**：按疼痛部位归经（详见附录经络循行速查）。
- 手三阳分主三动作：手不能前抬（前举）=大肠经；手不能梳头（外展）=三焦经；手不能后摆（后伸）=小肠经。
- 肩痛三经定位：大肠经行肩前、小肠经行肩后、中间为三焦经；肩井后三寸处痛属小肠经，其间属三焦经。
- 背痛：正中=督脉；两侧上下=膀胱经；环腰一圈横痛=带脉。
- 腰痛：正中=督脉；痛两边=膀胱经；横痛（命门以下）=带脉。
- 胸胁痛：肋骨外=阳维（外关）；肋骨内=阴维（内关）。
- 头痛：两侧（膀胱经）实症束骨、虚症委中；正中间督脉后溪；偏头胆经太阳透率谷；耳后三焦经初痛天井久痛中渚；额头痛中脘。
- 乳房硬块：乳头属肝经、乳上胃经、乳下肝经、乳中旁开一寸心包经、乳中旁开二寸脾经——按所在经络辨证取穴。

**路径 B｜经验信号归经**（不能指认时）：
- 病人说"周身无处不痛"、不能指明经络→**先开四关**（合谷+太冲），待能指出痛处再按经络取穴。
- 痛在大肠经与小肠经之间→三焦经；胸胁分不清何经皆痛→络病，下大包。

**路径 C｜压痛点定位（辅助）**：结合第四篇按压法，在本经上找最痛阿是。

> **原理**：取穴必须依经络走向选穴，不能"哪痛扎哪"；如肩痛不辨经就扎曲池，曲池只治大肠经之肩痛。

### 6.2 第二步：定虚实，选子母穴（补泻核心）

**判断虚实**（见 5.2），然后：
- **实症→泻子穴**；**虚症→补母穴**；虚实夹杂按比例先泻后补/先补后泻。
- 痛多酸少：先泻后补；酸多痛少：先补后泻；纯痛：泻；纯酸：补；麻：补且疗程长。
- 也可针病经**原穴**，配表里经**络穴**（原络治疗）——虚实皆治，一穴兼补泻。

### 6.3 第三步：五输穴通用选穴规则

**歌诀（记忆）**：井主心下满，荥主身热，俞主体重节痛，经主喘咳寒热，合主逆气而泄。

| 规则 | 主治 | 说明 |
|---|---|---|
| 病在脏→取井穴 | 深部脏病、心下满、动脉堵塞剧痛 | 井在末梢敏感，一寸针点刺 |
| 病变于色→取荥穴 | 面现五色（青肝赤心黄脾白肺黑肾） | 见 3.4 |
| 病在时间→取俞穴 | 按时间定时发作（如每日某时辰醒） | 按地支歌取该经俞穴；也可用荥穴 |
| 病变于音→取经穴 | 感冒声音变、声音从某器官出 | 取该经经穴 |
| 病起于饮食→取合穴 | 饮食不节、胀满、暴饮暴食 | 合穴 |
| 五脏不平衡→取原穴 | 安五脏 | 阳经原穴 |
| 井主冬天 | 冬病刺井 | 四季相应 |
| 合穴主秋、味主秋 | 味觉异常、口发金属味/甜/苦 | 治在合穴 |

> **多方案提示**：病在时间者，师门用荥穴、书（《针灸甲乙经》）用俞穴，皆效；荥穴较痛（"亲人用俞穴，敌人用荥穴"），临床可择取。

### 6.4 第四步：配穴法则（组合决策）

**足少阴肾经**（酉时）：涌泉（井·子穴，泻用然谷，急救苏醒、头顶痛）；然谷（荥·脑震荡放血、肾实泻用）；太溪（俞·候肾气、肾结石诊断）；复溜（经·母穴补肾虚、水肿）；照海（阴跷·喉病配列缺、夜发癫痫灸）；大钟（络穴）；水泉（郄穴·脚后跟痛）；阴谷（合·本穴）；横骨至俞府（腹部肾经外开一寸、胸部外开二寸）。**补泻**：母复溜、子涌泉（用然谷）。

**手厥阴心包经**（戌时·随节气）：天池（乳中旁开一寸）；曲泽（合·本穴冬至后）；郄门（郄·镇痛）；间使（经·母穴冬至后·手麻）；内关（络·配公孙治胃心胸、止吐催吐、通阴维）；大陵（俞·子穴夏至-冬至治心包实）；劳宫（荥·本穴夏至-冬至·退烧基准）；中冲（井·母穴夏至-冬至，补用曲泽）。**补泻**：随节气变母子（见 6.2）。

**手少阳三焦经**（亥时·随节气）：关冲（井·急救）；液门（荥）；中渚（俞·母穴夏至-冬至补虚）；阳池（原穴·消渴透大陵）；外关（络·通阳维·通生死桥退高烧、配临泣）；支沟（经·治便秘配照海）；天井（合·子穴夏至-冬至泻实）；翳风（耳鸣耳聋、牙关痛）；耳门（耳病·张口）；丝竹空（眼科放血）。**补泻**：随节气变母子。

**足少阳胆经**（子时）：瞳子髎/太阳（偏头痛·太阳透率谷）；听会（耳病）；风池（受风·鼻窦炎·对侧颧髎方向刺）；肩井（上焦要穴·必配足三里防昏倒）；日月（胆募）；京门（肾募·腰酸耳鸣）；环跳（骨之始·补法呼吸补泻·中风大穴）；风市（中风瘫痪大穴）；阳陵泉（筋会·透阴陵泉治膝风湿）；胆石点（胆结石诊断）；光明（络穴·眼科）；阳辅（经·子穴泻胆实、偏头痛）；悬钟/绝骨（髓会·脑病、中风）；丘墟（原穴）；临泣（俞·本穴·带脉病、时症）；侠溪（荥·母穴补虚、虚偏头痛）；足窍阴（井）。**补泻**：母侠溪、子阳辅。

**足厥阴肝经**（丑时）：大敦（井·本穴·疝气、妇科止血、阴部病）；行间（荥·子穴泻肝实、猛爆性肝炎）；太冲（俞·候血、开四关、时症）；蠡沟（络穴）；中封（经穴）；曲泉（合·母穴补肝虚·皮肤痒、阴挺）；章门（脏会·脾募·强土、奔豚）；期门（肝募·胸胁苦满、热入血室）；治肝三穴（右腿内侧·肝硬化肝癌诊断与治）；阴廉五里（求子穴·隔姜灸）。**补泻**：母曲泉、子行间。

## 第七篇 下针实施（手法）

### 7.1 针刺前检查清单（安全门·可勾选）
- [ ] 病人状态：无气血大虚、无酒后、无房事后、无大汗后、体力可
- [ ] 部位禁忌：孕妇禁针合谷、三阴交、腹部诸穴、肩井、昆仑；乳中禁针、神阙禁针；面部禁灸；多汗处少灸；天突/中府/缺盆不直刺；背部斜刺；哑门风府不灸
- [ ] 体位：一律**卧姿**（防晕针），幼儿可坐抱
- [ ] 针具：一人一针（现代不锈钢针，针身针柄接合处易断，下针留针身在外）

### 7.2 丈量（同身寸）
- 中指弯起两横纹头之间=1 寸；三指并拢=2 寸；四指并拢=3 寸。
- **看病人的手**，不能看医生自己的手；小儿用小儿的。
- 同身寸用于四肢及经络间；**腹部、胸部另有独立寸法**（腹部按神阙-曲骨比例分段取穴，不用同身寸）。

### 7.3 找穴要点
- **穴道绝不在肌肉上、骨上、筋上、血管上**；一定在：两肌肉缝隙、肌肉与骨之间、筋与筋之间、筋与肌之间、血管旁。
- 用**手感**摸质感：摸到缝隙、凹陷即为穴。
- 脚上穴多在骨头旁边（筋骨之间）；背部穴斜刺入两肋骨间。

### 7.4 进针深浅（决策）
- **季节**：春天浅、秋冬深（如钓鱼）。
- **病位**：病在皮毛→浅刺皮肌间；病在肌肉→肌肉；病在血脉→扎脉旁；病在肾→深刺至骨旁。
- **部位**："腹深似井，背薄似饼"——腹部可深、背不可深（扎到肺致肺气肿）。
- **胖瘦**：胖子深、瘦子浅；有的穴本就浅，不可强刺。
- **脏病深刺、腑病浅刺**；治水须深刺（一寸半起）；皮表病浅刺、骨病深刺至骨。

### 7.5 进针与引气（得气）

**进针**：
- 现代用针管直接拍进；不必叫病人咳嗽（古代针粗才咳嗽进针）。
- 刺动脉旁穴（太渊、经渠、列缺、合谷、和髎、颈侧等）：**先以指甲将血管拨开**，再沿指甲旁进针，勿刺静脉。

**引气（得气）**——下针后须待气至再行补泻：
- 气至标志：病人诉**酸、麻、胀**；或针孔周围出现**一圈粉红色**（扎到瘀血呈青黑色）。红圈大小反映体质（气虚无红圈、体壮红圈大）。
- 气未至的引气法（由轻到重依次尝试）：
  1. 左右捻转针，待酸麻胀
  2. 上下提插二下，气至则针下沉、有被吸入感
  3. 以手指在针上下皮肤轻推戳（气在表，不必重按），再捻转
  4. **呼吸引气**：病人吸气时出针（至皮层不拔出）、吐气时慢进针，出入随呼吸
  5. 仍无气=元气大伤，停针改用灸法
- 术者以自身气引气（病人极虚时）：轻握针柄（重握气不传）、放松关节、丹田吸气吐气、意想气随针透入。

> 针必用金属（肺属金、金能导气）；塑料针不能引气。

### 7.6 补泻手法（分类操作）

**总原则**：先引气，再补泻；补用阳数（单数 3/5/7/9），泻用阴数（双数 6）。补则出针按针孔（扪法），泻则不按针孔令邪外出。

**① 基本提插补泻（提豆许）**：
- 泻：气至后，针往前推一点点（如绿豆大）
- 补：气至后，针往上提（拉）一点
- 针初下勿太深，以免一推即过深

**② 捻转法**（骨边穴痛难施迎随时用）：得气后顺经气快速捻过、缓慢退回；勿单向一直捻（防滞针）。滞针处理：不可硬拔，在针上下一寸各补一针即松。

**③ 迎随法**：逆经气而刺=迎（泻）；顺经气而刺=随（补）。用于可迎随处（骨边剧痛处用捻转/插提替代）。

**④ 插提法**：顺经慢提快推为补；逆经快提慢推为泻。

**⑤ 呼吸补泻法**（用于肉厚处·俞募穴）：必先引气。
- 补：鼻吸口呼，病人吸气时边吸边慢提针至皮层，吐气将尽停顿之际快速按插到底（紧按慢提），三吸三按。
- 泻：鼻呼口吸，与补相反（紧提慢按），吐气慢插、吸气慢提。

**⑥ 烧山火（大补·治里寒）**：先引气；将皮下至骨约一寸分天、人、地三部，每部紧按慢提 9 数（三九二十七）。须肉厚处（足三里、三阴交、复溜、肾俞），勿在井穴。后加灸更佳。适应：胃寒、脚冰冷、肾寒。
**透天凉（大泻·治大热）**：先引气；针直插地部，紧提慢按 6 数，再人部 6 数、天部 6 数（三六十八）；起针不按针孔。适应：壮热、消渴中消、燥渴、实症发烧。

**⑦ 阳中引阴（先寒后热→先补后泻）/ 阴中引阳（先热后寒→先泻后补）**：寒多热少、酸多痛少→先补后泻；热多寒少、痛多酸少→先泻后补。

**⑧ 龙虎交战（镇痛）**：天、人、地三部，每部先顺气脉右转 9 数补，再反向 6 数泻；治剧烈疼痛（头痛牙痛癌痛外伤），近于针灸麻醉。**龙虎升降（插提·通关）**：三部各一补一泻，提至天部留针；治关节脱臼、骨折、风湿关节肿。

**⑨ 飞经引气四法**：
- 青龙摆尾（补·虚症）：持针柄左右轻摇 9 下，病人感热；须肉厚本穴/原穴。
- 白虎摇头（泻）：退方进圆，摇铃状。
- 苍龟探穴（补·积块痞块）：一退三进，逐次深入。
- 赤凤迎源（泻）：退方进圆同时摇针柄。
- 强手法毕一般不留针。

**⑩ 留气法（治痞块硬块肿瘤）**：远取穴（如胃经硬块取足三里、上巨虚、梁丘），针入先阳数九（紧按慢提 9 次），提豆许停约 5 分钟，再行阴数六；毕留针、出针不按孔。近取良性硬块用烧针/报刺（恶性坚硬粗糙者禁用）。

**⑪ 烧针（燔针·治良性痞块脂肪瘤化脓）**：针蘸麻油（禁汽油），斜火烧三次，速刺；先以火罐吸脓头（脓大用铍针）。三针法：上→下、前→后、后→前三向刺。
**报刺法（飞针引气·良性痞块）**：捏皮直刺块底捻转，提至皮层后依东、南、西、北、东南、东北、西南、西北八方向逐一斜刺到边际捻转，回原点直插捻转而出；出针不按孔。

**⑫ 子午捣臼（九入六出·治水胀）**：一寸距离内，进针慢提快推为补（9 次）、快提慢推为泻（6 次）；取水分、水道、关元、中极、阴陵泉（最大水穴）等；补泻同施一穴以引动三焦。针毕常即欲小便。

**⑬ 五门十变**：本穴可作母子经补泻；两穴相合可生另一五行（甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火）。取对侧、平补平泻、先后下针使两针相会。用于不便近身取穴时。

**⑭ 指针术（小儿·不开针）**：以手指代针。
- 开天河水：小儿高烧壮热，问男女，按小儿外关揉二三下往下推到四肢末梢，再找间使揉散天河水（开后必须散）。
- 推三关（食、中、无名指）：男孩寒症往上推去寒、热症往指尖推去热；女孩相反。
- 内关止吐催吐：压内关心想"不想吐"即止，"想吐"即吐。

**⑮ 放血法（三棱针/镵针）**：
- 部位：四肢末梢井穴（十宣）、头面（攒竹、丝竹空、瞳子髎、耳尖）、委中、大椎、金津玉液、龈交等。
- 手法：翻手轻点、准而可控深浅方向；刺后挤一两滴血即可（不必放多）。
- 急救放血（十宣）：一次捉五个手指快速刺完一起挤；脚趾同；百会放血（脸全红=刚中风）。
- 委中放血（解毒大穴·皮肤病）：扶墙踮脚，拍揉至青筋冒出即刺令毒血出。

### 7.7 留针与起针
- **留针时长**：一般 20 分钟；中风可留 30-60 分钟至一两小时；重症中风留 1-2 小时每 10 分钟运针。新病初病留 3-5 分钟；久病留 20 分钟。
- **单刺（幼儿）**：针进去捻一捻即出，不留针；**14 岁以下**不留针，14 岁以上留针。
- **起针法**：指头压皮肤，慢慢拔出，出毛孔时**停 30 秒**再慢慢出来→一滴血不出；勿挑勾出力。

## 第八篇 治疗中的观察与收尾

### 8.1 观察得气与反应
- 下针后观察**粉红圈**是否出现（气至）；补泻后观察病人感觉（补则温热、泻则清凉）。
- **病进病退**：见 3.6。若病在进，说明处方/穴道错，须重议；病在退则不变，等病好为止。
- **晕针处理**（急救式）：先下人中（痛则醒）；叫病人躺平、打开胸腔扣子、空气流通；仍不醒则十宣/脚趾放血。晕针不会死，多数因姿势不对（故一律卧姿）。

### 8.2 治疗结束状态（好转与痊愈信号·可勾选）
治到以下信号出现，才算是"病退/将愈"：
- [ ] **能睡**：一觉到天亮（肝病者一点-三点不再醒；胆结石者半夜不再醒；肺病者三点不再醒）
- [ ] **胃口复**：有饥饿感、能进食（"有胃气则生，无胃气则死"；重病后胃口渐复者生）
- [ ] **二便调**：大便每日有时、小便通利色正
- [ ] **手脚温、头面身体凉**：阴阳平衡恢复正常
- [ ] **病退方向**：痛由身上往四肢走
- [ ] **面色/眼诊转正常**：如鸡爪血丝消失、黄疸退
- [ ] **特定压痛点消失**：背俞压痛减/消、胆石点不痛、消积穴不痛等
- [ ] 脏腑病恢复的特殊信号：腑病恢复时**中午会饿**；脏病恢复时**半夜醒来很饿**；感冒发烧第二天中午胃口恢复为愈

### 8.3 疗程安排
- **隔日治疗**（一三五、二四六）；扎一次去八成则隔日再扎，须**完全去掉才停止**。
- 一天开一次八法/子午流注后同病人再扎无效。
- 针灸应**立竿见影**；无效多因未针中穴道，须复按取穴。

### 8.4 针后禁忌（交代病人）
- [ ] 针后不喝酒（须等 72 小时后再喝）
- [ ] 不食辣椒等辛辣
- [ ] 不用麻油
- > 此三者乱阳气行走。

## 第九篇 安全与禁忌总表（查漏汇总）

| 类别 | 禁忌/注意 |
|---|---|
| **针刺时机** | 气血大虚、重病、失血多、无元气、房事后、运动大汗后、酒后、体力不够——不下针 |
| **孕妇** | 禁针合谷、三阴交、腹部诸穴（脐以下）、肩井、昆仑（堕胎）；补合谷泻三阴交=堕胎，泻合谷补三阴交=安胎 |
| **禁针穴** | 神阙、乳中、乳根（不针）、巨骨、石门（妇人禁）、五里（下有动脉）——或仅定位不作常规针 |
| **禁灸** | 热症、感冒发烧、多汗处（手掌、委中）、津液多/眼/阴部、面部、乳中、哑门风府、经渠等脉上穴、肛门（痔疮热） |
| **深刺危险** | 背部禁深（肺气肿）、天突/中府/缺盆不直刺、肩井不可深（致昏迷，须配足三里）、胸部沿肋斜刺、哑门对舌根刺至碰椎 |
| **补泻原则** | 补用阳数、泻用阴数；补按针孔、泻不按针孔；先引气再补泻 |
| **针具安全** | 下针留针身在外（针柄接合处易断）；断针两指压旁肉取出，断针不会跑 |
| **体位** | 一律卧姿防晕针；晕针下人中、开扣、十宣放血 |
| **针刺深浅** | 春浅秋冬深；病在皮毛浅、骨深；腹深背薄；胖深瘦浅 |
| **放血** | 翻手轻点、挤一两滴即可；头部放血勿深刺脑内 |
| **灸法安全** | 隔姜/隔盐/隔蒜/米粒灸；灸单数；**灸之大原则：痛灸到不痛止、不痛灸到痛止（灸至病根为度，如肿瘤灸至不痛处停、鼻窦炎/鸡眼灸三五个视深浅）**；灸后水泡消毒刺破排水勿撕皮；灸膏肓须灸足三里导热下行；烧针禁汽油 |

### 附录 D：家庭养生与日常保健（教程原文有据）

日常保健非治病方案，供养生参考；有病仍按主流程辨证。

- **耳按摩**：洗面后压/按摩耳朵约 **20 分钟**（运动为**旋转式**非直线，如拧毛巾排水），耳朵按摩时全身内脏随之而动；坚持每日做，防伤风感冒（倪师母传习惯，"全家感冒独她无病"）。
- **保健灸**：**男人多灸关元、足三里**（防中年后夜尿频、摄护腺问题；灸关元救小肠火）；灸**膏肓**（虚劳重症，原文"灸百壮无所不疗"，灸后**必灸足三里导热下行**）；灸单数壮。
- **小便训练**：小便时出力（收摄发力），训练摄护腺。

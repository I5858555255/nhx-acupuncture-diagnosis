## 项目定位

本项目包含一套主技能与一套系统的验证实验：

1. **`doubao-acupuncture-diagnosis`（主技能，v14 正式版）**——LLM 辨证执行引擎：随技能携带《诊断与针灸实施指南》（倪师人纪针灸篇整理版，9 篇 + 4 附录）、特效库（31 条）、治则手法库（57 条）、知识条目（131 节）、典型案例示范集（8 例）。输入任意症状/主诉，按 9 环节流程输出"带依据的诊断 + 四层选穴 + 下针明细 + 禁忌 + 疗程痊愈判断"。v14 自 SF10-M7 受控转正（在 v13 guarded 基线上仅新增 R7 踝部两线组：外踝胆经痛→丘墟侠溪、单踝扭伤肿→商丘透丘墟，两线互斥；M7-D 7/7 验收通过；v13 为上一代正式基线，备份于 `_backup/`，完整版本历史见 `doubao-acupuncture-diagnosis_v13rc1/变更记录.md`、`doubao-acupuncture-diagnosis_v14r7/变更记录_R7.md` 与主目录 `变更记录_SF10_v14.md`）。
2. **`盲法对照实验`**——358 份病案普查 → 93 块针灸首诊案抽盲法测试集（症状/原案处方一一配对）→ 多轮技能迭代（v140 基线至 v12 终版）+ 逐轮盲法回归判分，并自 SF10-M1 起转入**原案选穴归因驱动**的方法论优化范式（每处差异反推原书/指南依据，择优更新方法论）。这是本项目的核心证据链。

> 曾含第二套对照技能 `renji-zhenjiu/`（book2skill 流水线产物）：经与主技能逐项比对，其知识主体已被主技能覆盖，仅 2 处有原书依据的增量（灸之大原则、家庭养生）已蒸馏并入主技能指南（第九篇灸法安全行、附录 D）；该目录已在远程仓库移除，本地保留 book2skill 工作区供复用。

## 方法论：技能设计

技能按倪师《人纪·针灸篇》方法论整理为 **9 环节执行契约**：

```
1 接诊问诊 → 2 望诊观察 → 3 触诊按压 → 4 辨证定案（八纲/虚实/寒热/五行/时辰/脏象）
→ 5 双主干分流（局部特效穴 vs 辨经辨证）+ 特效库强制反查 + 压痛点直接取穴
→ 6 选经（循行定位→经验信号→压痛点三通道）
→ 7 选穴（四层模板：对症 ≥3 / 俞募背俞条件化 / 八脉交会 / 特效奇穴，主穴以 7 为目标）
→ 8 下针实施明细 → 9 收尾（痊愈信号/疗程/禁忌）
```

关键机制（均有原书/指南依据，九轮中逐条实证）：

| 机制 | 加入轮 | 实证效果 |
|---|---|---|
| 特效库强制反查 + 四层模板 | R1 | 同 16 案 30.4%→44.1% |
| 反查精准化（1–3 穴宁缺毋滥）+ 俞募条件化 + 单操作识别 | R2 | 奇穴命中率 10.2%→24.2% |
| 主诉焦点纪律 + 特效压痛直接取穴 + 耳穴归并 | R3 | 107 案 0→100%、340/312 0→100% |
| 局部专科穴优先 + 透刺端点惯例 + 天应灸触发 | R4 | 117 案 0→0.75、194/216 系列升 |
| 主穴扩量 6–8 + 兼证调理保留 + 天应灸条件收紧（攻坚组） | R5 | 重合率 +6.8pp（最大单轮涨幅） |
| 主穴以 7 为目标 + 八脉 2 组普遍化 | R6 | 复现率峰值 43.9% |
| **检索纪律（逐穴附原文出处，防幻觉）+ 一页决策树** | **R8（GH 蒸馏）** | 执行方差 26%→80%、依据 100% |
| **v6 穴量规则 × 检索纪律（综合最优）** | **R9** | 主+佐召回率 50.9%（新口径，九轮最高；旧口径 49.1%） |
| **证据驱动穴量（删除强制凑穴）+ 灸法奇穴移出主穴 + 八脉异组仅留第 1 组 + 背俞仅压痛依据 + 乳癌链补梁丘 + 318 类规则补强** | **SF10/v11** | 主穴 F1 42.2%（+4.3pp）、精确率 45.2%（+8.7pp，十轮最高）、零命中案 3→1（201/318 救回） |
| **原案选穴归因驱动（M1 审计 28 案 → M2 归纳 13 条方法论条目 → M3 落地：肩髃应腋下/神门大陵归心经/心脏三针/手麻分经/外关阳维/水肿利水整组/三痹/鼻透/肝关/肺癌组/下焦泌尿等）** | **SF10/v12** | 主穴 F1 48.5%（+6.3pp）、全处方召回率 60.0%（首破 6 成）、11 条有收益/1 条无收益/0 负收益 |
| **残余归因+受控验证（M5-C 322 错/13 候选 → D 消融+候选验证 → v13 盲法：R2 肺积水分型分流 / R3 五十肩曲池足三里优先级 / RC-5 神门大陵同出 / RC-6 膀胱经腰背整组；再经 M6 RC-5/6 过触发约束修正 → guarded 转正）** | **SF10-M5/M6 v13** | 主穴 F1 50.5%（+2.0pp，FP 再降 19 个）、Jaccard 36.3%、核心集 F1 52.4%；28/58 分组双改善（+3.8pp/+1.0pp vs v12） |

## 方法论：真盲法对照实验

- **数据**：358 份倪师门诊病案 doc 全量普查（olefile piece-table 解析）→ 140 个针灸首诊块（93 块有方案 = 86 可判分 + 7 特殊标注单列；47 块针灸栏空为纯中药案）。
- **盲法定义**：子代理**只读症状文件**独立辨证选穴，与 gold（原案处方）对照；禁读原案处方与历史盲法产物。
- **判分口径**（旧版）：别名归并（肩禺/肩臑→肩髃等）、复合单元端点（X+Y 拆两穴、A透B 取两端）、耳穴归并、剔"天應導引"手法注。
- **指标**（旧版）：主穴重合率（主）、主+佐重合率、精确率、命中/出穴比、主穴均值、<40% 案数；R8 起增加执行忠实度（同规则重执行一致案数）与逐穴依据齐全率。

> **⚠ 评分口径修正（2026-10-14，BENCHMARK-AUDIT-01）**：外部独立审查发现旧评分器存在三处口径问题——①"重合率(主)"分母为 gold 穴数，实为**召回率**而非"命中/出穴"；②精确率分母用未展开的主穴单元数，透刺/复合展开后可能 >100%；③九轮使用了两套预测归一化函数（v140/v2 与 v3–v9 不同）；④膝五针/三皇穴在 gold 中同时保留父级组名与组成穴，重复计数。现已统一归一化、按点级 precision/recall/F1/Jaccard 重算全部九轮（结果在 `benchmark_v2/`，旧数据只归档未覆盖）。**下表保留旧口径数值供对照，新口径数值见下文与差异报告。**

- 统一口径下：九轮内"recall 峰值 v6、precision 峰值 v5"的格局仍成立；**SF10 的 v12 已全面刷新全部指标峰值为历代最高**（recall +6.7pp vs v6、precision +8.7pp vs v11、F1 +8.6pp vs v11、主+佐 recall 首破 6 成）；**M5/M6 的 v13 在 v12 之上再提升**（recall +1.6pp、precision +2.4pp、F1 +2.0pp、Jaccard +2.1pp，FP 净降 19 个）——归因→原书证据→受控验证→约束修正的闭环持续有效，主穴点数均 7.8。
- 差异归因（v9）：gold 复合组口径修正使 11 案 recall 全部上升（膝五针/三皇穴不再重复计数，如 8_01 0.444→0.875）；精确率分母由单元数改点数，旧精确率 44.0% 高估约 7.4pp（实测 36.5%）。
- 分层（v9）：复诊跟随案 20 案 recall 30.9% vs 锚案/首次案 66 案 47.8%——复诊链案显著拖低均值；v11 复诊层 F1 +5.38pp、首诊层 F1 +2.35pp（见 `sf10_阶段G/横向对照表_v11.md`）；v13 复诊跟随层 F1 48.7%、乳癌链 66 F1 58.3%、M1-28 F1 59.1%、未M1-58 F1 46.3%（v13rc1 判分汇总）。
- 确定性：同一评分器连续 3 次输出 SHA-256 完全一致；canonical_scorer 单元测试 30/30 全过（指标公式/复合穴展开/透刺端点/别名归并/gold 去重/空预测/空 gold）；点级 precision 超 100% 违规案 0；v12 历史结果经 canonical 复算哈希逐字节一致。
- **当前 86 案定位为开发集成绩**（多轮迭代复用同一测试集）；按患者链 leave-one-chain-out 分组验证（M6-D）结果与覆盖率见 `sf10_阶段M5/G_验收/SF10-M6-完整总结.md`；外部 holdout 测试集待新数据到位后建立（`benchmark_v2/` 内已标记待办）。

### 收敛结论

1. **主穴规模最优区 6.0–6.9 窄带**：R6 扩穴（+0.78 穴）增 2.4pp 但边际命中降至 33%；R7 删穴反跌 4.2pp（删掉的是有效命中）——全局扩缩已边际无效；v11 走"证据驱动"（点数均 7.08、十轮最精简）反而同时拿下精确率与 F1 峰值；v12 按原书证据"整组装配"回升至点数均 7.83，实现 recall 与 precision 同升。
2. **分数由穴量规则决定，执行纪律消灭执行噪声**：R8（规则不变只加纪律）分数逐位不变但执行方差≈0、依据 100%；R9（最优穴量×纪律）忠实度 26%→80%。
3. **最终版 = v14（SF10-M7 受控转正）**：v13 已由 M5/M6 guarded 转正（M5 残余归因 86 案 322 错/13 候选 → D 受控验证合入 4 条 → v13 盲法 → M6 RC-5/RC-6 过触发约束修正 → 7 项门槛全过）。v14 在 v13 基线之上**仅新增 R7 踝部两线组**（外踝胆经痛→丘墟侠溪；单踝扭伤肿→商丘透丘墟，两线互斥；解溪/足临泣按 M7-B 审计不入任一线）——M7-B 86 案触发扫描确认无跨案误触、M7-D 受控实验 7/7 全过；M7.1 查证裁决：118"单踝局部痛"无原书依据（教程明文"商丘透丘墟专治脚扭伤"），证据不足未合入，如实记录。
4. **剩余差异为信息天花板**（不可规则修复）：复诊链/同前穴案约 20 个（gold 是历史处方，盲法无历史，M5-B 三条件实验证实：提供无处方既往诊断信息也不改变选穴——缺口在规则侧 follow-up 锚点维持机制，R4 候选因 symptom-only 不可触发未合入）；信息不足案（216_04 等，脉/触/耳诊字段缺失）；M2-07 外伤史仅存于处方括注（13_01），诊断输入不可触发。
5. **评分基建已按外部独立审查整改**（BENCHMARK-AUDIT-01 + M5-F canonical 化）：统一归一化、点级指标、canonical_scorer 单点实现（30/30 单测、v12 复算哈希逐字节一致）、逐案审计日志、复诊链分层。**当前"几成"的稳妥表述**（v13，开发集宏平均）——86 全量：主穴召回率 53.8%、精确率 52.0%、F1 50.5%、Jaccard 36.3%、主+佐 F1 50.5%；64 核心集：主穴召回率 58.3%、精确率 52.4%、F1 52.4%。均为**开发集成绩**（含 in-sample 乐观偏差声明），外部 holdout 泛化验证待新数据（已挂起待办）；按链分组验证见 `sf10_阶段M5/G_验收/SF10-M6-完整总结.md`。

# nhx-acupuncture-diagnosis · 倪海厦针灸辨证 AI 技能与盲法对照实验

> 将倪海厦《人纪·针灸篇》辨证选穴方法论蒸馏为 LLM 可执行技能，并用**真盲法对照实验**（93 案、九轮迭代）量化验证其对原案选穴的复现能力：**主穴重合率 27.4% → 42.2%，主+佐 49.1%（九轮最高），执行忠实度 26% → 80%，逐穴依据齐全率 100%**。

## 项目定位

本项目包含两套倪师针灸 AI 技能与一套系统的验证实验：

1. **`doubao-acupuncture-diagnosis`（主技能，v9 最终版）**——LLM 辨证执行引擎：随技能携带《诊断与针灸实施指南》（倪师人纪针灸篇整理版，9 篇 + 3 附录）、特效库（31 条）、治则手法库（57 条）、知识条目（131 节）、典型案例示范集（8 例）。输入任意症状/主诉，按 9 环节流程输出"带依据的诊断 + 四层选穴 + 下针明细 + 禁忌 + 疗程痊愈判断"。
2. **`renji-zhenjiu`（第二套技能）**——由 book2skill 流水线生成的对照技能，用于机制对比。
3. **`盲法对照实验`**——358 份病案普查 → 93 块针灸首诊案抽盲法测试集（症状/原案处方一一配对）→ 九轮技能迭代 + 逐轮盲法回归判分。这是本项目的核心证据链。

## 方法论：技能设计

技能按倪师《人纪·针灸篇》方法论整理为 **9 环节执行契约**：

```
1 接诊问诊 → 2 望诊观察 → 3 触诊按压 → 4 辨证定案（八纲/虚实/寒热/五行/时辰/脏象）
→ 5 双主干分流（局部特效穴 vs 辨经辨证）+ 特效库强制反查 + 压痛点直接取穴
→ 6 选经（循行定位→经验信号→压痛点三通道）
→ 7 选穴（四层模板：对症 ≥3 / 俞募背俞条件化 / 八脉交会 / 特效奇穴，主穴以 7 为目标）
→ 8 下针实施明细 → 9 收尾（痊愈信号/疗程/禁忌）
```

关键机制（均有原书/指南依据，九轮中逐条实证）：

| 机制 | 加入轮 | 实证效果 |
|---|---|---|
| 特效库强制反查 + 四层模板 | R1 | 同 16 案 30.4%→44.1% |
| 反查精准化（1–3 穴宁缺毋滥）+ 俞募条件化 + 单操作识别 | R2 | 奇穴命中率 10.2%→24.2% |
| 主诉焦点纪律 + 特效压痛直接取穴 + 耳穴归并 | R3 | 107 案 0→100%、340/312 0→100% |
| 局部专科穴优先 + 透刺端点惯例 + 天应灸触发 | R4 | 117 案 0→0.75、194/216 系列升 |
| 主穴扩量 6–8 + 兼证调理保留 + 天应灸条件收紧（攻坚组） | R5 | 重合率 +6.8pp（最大单轮涨幅） |
| 主穴以 7 为目标 + 八脉 2 组普遍化 | R6 | 复现率峰值 43.9% |
| **检索纪律（逐穴附原文出处，防幻觉）+ 一页决策树** | **R8（GH 蒸馏）** | 执行方差 26%→80%、依据 100% |
| **v6 穴量规则 × 检索纪律（综合最优）** | **R9** | 主+佐 49.1%（九轮最高） |

## 方法论：真盲法对照实验

- **数据**：358 份倪师门诊病案 doc 全量普查（olefile piece-table 解析）→ 140 个针灸首诊块（93 块有方案 = 86 可判分 + 7 特殊标注单列；47 块针灸栏空为纯中药案）。
- **盲法定义**：子代理**只读症状文件**独立辨证选穴，与 gold（原案处方）对照；禁读原案处方与历史盲法产物。
- **判分口径**（全程统一）：别名归并（肩禺/肩臑→肩髃等）、复合单元端点（X+Y 拆两穴、A透B 取两端）、耳穴归并、剔"天應導引"手法注。
- **指标**：主穴重合率（主）、主+佐重合率、精确率、命中/出穴比、主穴均值、<40% 案数；R8 起增加执行忠实度（同规则重执行一致案数）与逐穴依据齐全率。

### 九轮迭代全景（同 86 案、同 gold）

| 轮次 | 主穴均值 | 重合率(主) | 主+佐 | 精确率 | 命中/出穴比 | <40%案 |
|---|---|---|---|---|---|---|
| 140 基线 | 5.87 | 27.4% | 33.2% | 35.7% | 35.0% | 67 |
| R2 | 5.33 | 29.5% | 34.9% | 41.6% | 40.2% | 61 |
| R3 | 5.31 | 32.6% | 38.5% | 42.5% | 41.1% | 58 |
| R4 | 5.48 | 34.7% | 40.9% | 44.2% | 42.9% | 58 |
| R5 | 6.08 | 41.5% | 46.5% | **48.4%** | **47.8%** | 43 |
| R6 | 6.86 | **43.9%** | 48.7% | 46.5% | 46.1% | 37 |
| R7（删穴收敛，失败） | 6.11 | 39.7%↓ | 47.5% | 45.4% | 44.8% | 50 |
| R8（检索纪律，规则=v7） | 6.10 | 39.7% | 47.5% | 45.4% | 44.8% | 50 |
| **R9（v6 规则×纪律）** | **6.90** | **42.2%** | **49.1%** | 44.0% | 43.5% | 41 |

### 收敛结论

1. **主穴规模最优区 6.0–6.9 窄带**：R6 扩穴（+0.78 穴）增 2.4pp 但边际命中降至 33%；R7 删穴反跌 4.2pp（删掉的是有效命中）——全局扩缩已边际无效。
2. **分数由穴量规则决定，执行纪律消灭执行噪声**：R8（规则不变只加纪律）分数逐位不变但执行方差≈0、依据 100%；R9（最优穴量×纪律）忠实度 26%→80%。
3. **最终版 = v9**：v6 穴量规则（主穴以 7 为目标、八脉跨证普遍 2 组）× 检索纪律 × 一页决策树。
4. **剩余差异为信息天花板**（不可规则修复）：复诊链/同前穴案约 25 个（gold 是历史处方，盲法无历史）；信息不足案（201/318 等，脉/触/耳诊字段缺失）；个体侧重差异 3 案（207 手腕桡侧 gold 太渊——原书无"桡侧→太渊"记载，按"无原书依据不添加"约束未强行规则化）。

## 复现指南

```bash
# 1. 盲法测试集
盲法对照实验/盲法93/            # case_list.json + symptoms/93 + prescriptions/93

# 2. 判分（每轮独立可复算）
cd 盲法对照实验/盲法93_v9/
python gold_parse93v9.py         # gold 解析（别名/复合单元/耳穴归并/剔手法注）
python score93v9.py             # 判分（重合率/精确率/命中出穴比）
# 输出：判分明细.csv（含九轮对比列）、判分汇总.json

# 3. 全量普查（doc → 针灸首诊块）
盲法对照实验/_scan_all.py / _extract_all.py / _make93.py / _make140.py
# 产物：全集针灸首诊/（140 块）、首诊针灸方案核验清单.csv、_acup_zones_all.txt

# 4. 技能使用
# 将 doubao-acupuncture-diagnosis/ 作为 Agent Skill 安装；SKILL.md 中知识条目为相对路径，
# 运行时按本地实际位置读取；无本地文件时凭指南 6.5 压缩版取穴，不虚构。
```

# 阶段 1.5 任务说明 — 三重验证（V1/V2/V3）

按 `vendor/cangjie-skill/methodology/03-stage1.5-triple-verify.md` 对 candidates/ 每个候选执行：
- **V1 跨域**：书中至少 2 个独立段落有佐证？
- **V2 预测力**：能用它回答一个书里没明说的新问题吗？
- **V3 独特性**：不是任何聪明人都会说的常识吗？

通过 → 写入 `verified.md`（保留判定理由）；不通过 → 写入 `rejected/<id>.md` 并附原因。
完成后把「通过 N 个 + 淘汰 M 个」列表**展示给用户轻确认**。

  title: 病进病退判断框架
  type: framework
  source_chapter: 第一章·针灸的使用时机
  source_quote: |
    "当病进时，是由四肢末梢往身上走……而病退时，就会由身上往四肢走。"
  summary: |
    判断病情走向的两条路径：病由四肢末梢向躯干走=病进（当前处方或取穴错误，必须改方）；
    病由躯干向四肢走=病退（处方与穴道不能改，保持原方案至痊愈）。
    这是针灸临床中决定"是否调整方案"的第一判据，可迁移到任何治疗方案的疗效监控。

- id: f02
  title: 辨证选穴决策框架（归经→虚实→法则）
  type: framework
  source_chapter: 全书贯穿（第二、四、五、六章）
  source_quote: |
    "你要知道经络在那，你才知道如何选择穴道下针啊！……确定是那一条经产生的痛，我们在该经的子穴或母穴做补泻，或者在原穴上做补泻就可以了。"
  summary: |
    针灸选穴的通用决策路径：①先定病位归经（痛在哪条经、病在哪个脏腑）；
    ②再辨虚实寒热（虚喜按、实拒按；痛几天为新、几个月为久；寒热看小便/颜色/触感）；
    ③按法则取穴（经络四肢痛→子母补泻；内科脏腑病→俞募治疗；骨伤急症→会郄治疗；时间病→俞穴/荣穴）；
    ④左病右治、右病左治（四肢对称）。全书反复以"必须知道经络走向"作为一切选穴的前提。
  tags: [decision, acupuncture, differential-diagnosis]

- id: f03
  title: 子母补泻取穴法
  type: framework
  source_chapter: 第三、四、五章（五行基础与各经应用）
  source_quote: |
    "虚则补其母，实则泻其子……所以你可以看到任何阳经的井穴都是金……补井当补合，泻井当泻荣。"
  summary: |
    以五行生克定补泻：每条经的穴性按木火土金水（阴经）或金水木火土（阳经）排列，
    属性与经相同=本穴，生经者=母穴（虚症补之），经所生者=子穴（实症泻之）。
    特殊规则：母穴为井穴时"补井当补合"（在合穴上补），子穴为井穴时"泻井当泻荣"（在荣穴上泻）；
    心包/三焦经的子母穴随夏至冬至属性切换而改变。适用于经络四肢痛。
  tags: [decision, five-elements, acupuncture, mother-son]

- id: f04
  title: 五行生克截法（治未病阻断传变）
  type: framework
  source_chapter: 第三、四、五章（五脏治症贯穿）
  source_quote: |
    "当我们发现木有问题的时侯，我们先去强土,再去强肾。就可以把病堵住了。……我们先用截法，把火加强，肾脏病就不会恶化。"
  summary: |
    治病的传变阻断框架：脏腑按五行相克顺序传变（肝病克脾→脾病克肾→肾病克心……），
    治疗时先强"将被克之脏"（如肝病先强土、心病先强金/肺），使病不再前进，再图根本；
    拦不住再截下一环（金→木→土），逐层设防。同时把"相生=正常、相克=病态"作为判断脏腑协调的基线。
  tags: [decision, five-elements, disease-progression, prevention]

- id: f05
  title: 俞募治疗 / 会郄治疗 / 原络治疗 / 本穴治疗 分工框架
  type: framework
  source_chapter: 第五章·五俞穴治疗与原络治疗、俞募治疗与会郄治疗
  source_quote: |
    "俞募治疗大部分是用在治内脏病。如果是肺经痛……子母穴大部分是用在经络痛或四肢痛。内科病用俞募治疗法。"
  summary: |
    按病性分派治疗法则的决策表：内科脏腑病→俞募治疗（背后俞穴+前面募穴同下）；
    骨伤/急症/局部痛→会郄治疗（八会穴+郄穴）；经病久痛/表里同病→原络治疗（原穴+络穴）；
    属性相同者→本穴治疗（调木火土金水循环）。多法则可叠加（如胃病=俞募+会郄+足三里）。
  tags: [decision, acupuncture, treatment-rules]

- id: f06
  title: 近取穴 / 远取穴决策
  type: framework
  source_chapter: 第四、六章（各经穴位与治症）
  source_quote: |
    "在这个器官的周围，选择穴道就是近取穴。在四肢上找就是远取穴。"
  summary: |
    取穴空间框架：病位附近取穴=近取穴（局部症状、急性痛、实证），
    四肢远端循经取穴=远取穴（远端脏腑病、调理）。近取穴多无补泻问题可直下，
    配合远取穴效果更好（如腰痛近取肾俞+远取委中）。
  tags: [decision, acupuncture, spatial]

- id: f07
  title: 导引法（目标+引导双针）
  type: framework
  source_chapter: 第四、五章（取穴与补泻手法）
  source_quote: |
    "导引就是一个目标，你一下到第十一椎，就等于是告诉身体，我要气血集中在这个点上……这时候，你一下子穴，气血又流回来。"
  summary: |
    选穴引导框架：先下一针在病位（目标点，如某椎、某痛处）引导气血集中；
    再按补泻法则（子穴/母穴等）下第二针，使气血回流到目标点加强疗效。
    也用于手麻等：对侧下针（子母补泻）+同侧导引。核心是"目标+引导"两针配合的思考方式。
  tags: [decision, acupuncture, qi-guidance]

- id: f08
  title: 天应穴（阿是穴）压痛点取穴
  type: framework
  source_chapter: 全书贯穿（各经穴位）
  source_quote: |
    "阿是穴真正的精神，并不是'啊啊啊！是是是!'，而在这下针的意思。……找到阿是穴以后，针一下，那个痛马上就去掉了。"
  summary: |
    取穴定位框架：沿经络走行按压，找到病人最痛的点（压痛点）即下针点，
    而非"哪里痛扎哪里"的乱扎。用于耳针选点、结石痛点、局部硬块（天应灸）等。
    是诊断与治疗合一的手段：压痛点存在=病在，压痛消失=病愈。
  tags: [decision, acupuncture, palpation]

- id: f09
  title: 担法与截法
  type: framework
  source_chapter: 第四章·担法与截法
  source_quote: |
    "在两个穴道中间，一针下去就解掉了。这就叫担法。……在出血的位置上一寸下针……两针下去一定止血。这是一个截法。"
  summary: |
    两种针刺手法框架：担法=两处同痛（如背两点痛）时在两痛点中点下一针化解（禁用于神阙、乳房等危险区）；
    截法=止血/阻断病势（出血处向身侧上一寸逐针拦截；灸疱疹头尾=截断蔓延；五行截法阻断传变）。
  tags: [technique, acupuncture, bleeding-control]

- id: f10
  title: 对称治疗法（左病右治、右病左治）
  type: framework
  source_chapter: 第一、四章（各经治症）
  source_quote: |
    "临床下针是左病右治、右病左治。"
  summary: |
    取穴空间框架：四肢与对称部位疼痛，取对侧同名或对应穴（如左脚后跟痛下右手大陵、
    委中痛下对侧尺泽/曲泽、太渊痛下对侧太溪）。身体缺失时用对称替代（无左手下右脚）。
    背面俞穴等中线两侧穴则两边同下（俞募治疗不左病右治）。
  tags: [decision, acupuncture, symmetry]

- id: f11
  title: 背俞穴压痛点诊断图谱
  type: framework
  source_chapter: 第四章·膀胱经（俞穴各节）
  source_quote: |
    "当用手指头压的时候，如果有心脏病，压第五椎就会痛。肺有问题时，压第三椎就可以感觉出来。"
  summary: |
    诊断框架：督脉旁开一寸半（及三寸）的背俞穴是脏腑的诊断窗口——
    第三椎=肺、第五椎=心、第六椎=督脉（血癌）、第七椎=膈（血）、第九椎=肝、第十椎=胆、
    第十一椎=脾、第十二椎=胃、第十三椎=三焦、第十四椎=肾。
    压痛点存在=该脏腑有病；治疗后压痛消失=病愈。也用于治未病筛查（如压第三椎痛=肺癌风险）。
  tags: [diagnosis, palpation, acupuncture]

- id: f12
  title: 眼诊法（五色五脏）
  type: framework
  source_chapter: 第四章·眼诊法
  source_quote: |
    "眼白的地方……是诊断肺的地方。眼睛内眦……是诊断心脏的地方。……瞳孔都是黑色的，所以查肾脏查瞳孔。"
  summary: |
    望诊框架：眼白看肺（白块/面包屑样=肺病）、内眦看心（红）、瞳孔看肾（灯光照射收缩=肾阳足；
    不动=肾阳虚；放大=死兆）、瞳孔外圈看脾（土，1/3 比例、密纹=正常）、再外圈看肝（木，2/3 比例）。
    正常结构=肾阴藏、阳来阴退；结构比例改变=对应脏受伤。可快速筛查心肺肝肾脾问题。
  tags: [diagnosis, inspection, five-organs]

- id: f13
  title: 耳针诊断法（倒置婴儿图+压痛点）
  type: framework
  source_chapter: 第六章·耳针治疗
  source_quote: |
    "把耳朵图倒过来时……这个耳朵就像个小baby……这是头（耳垂）嘛，这头在这，脊椎骨嘛，这尾椎……从这边开始就是我们的内脏。"
  summary: |
    诊断+治疗框架：耳廓倒置如婴儿（耳垂=头、耳轮=脊椎、对耳轮=躯干四肢、三角窝=子宫卵巢），
    用圆头探针/筷子沿耳廓按压找压痛点（阿是穴），痛点=对应部位有病；
    确定后埋耳针（图钉式，留 6 天/夏天短冬天长，保持干燥）即可治疗。
    虚实判断：凸起=实（如肿瘤），凹陷=虚。可诊断可治疗可验证疗效。
  tags: [diagnosis, ear-acupuncture, palpation]

- id: f14
  title: 望诊辅助（眼袋/脸色/发/足温）
  type: framework
  source_chapter: 第四章·肾经、心经、膀胱经
  source_quote: |
    "眼袋下方就是肾的位置……眼袋位置暗暗黑黑的，就表示肾脏已经受伤了。"
  summary: |
    快速体检框架：眼袋暗黑=肾伤、卧蚕样凸起=水肿；脸颊赤红蝴蝶斑=心脏营养逆流（红斑狼疮征）；
    头发枯干蓬松不反光=肾气将绝；脚冷=小肠火衰/寒水/下焦有积，脚热=健康（无癌判断依据）。
    望诊+问诊（睡眠时辰、大小便、口渴饮水）组合即可完成大部分初筛，脉诊为辅助。
  tags: [diagnosis, inspection, health-screening]

- id: f15
  title: 补泻手法执行框架
  type: framework
  source_chapter: 第五章·呼吸引气法、烧山火透天凉等
  source_quote: |
    "补完以后，针再提一点点出来……手快转是顺经，再慢慢转回来，这是捻转法。用三补、五补、七补、九补都可以，用阳数来补。"
  summary: |
    补泻执行框架：得气（酸麻胀）为前提；捻转补泻（顺经快转为补、逆经为泻）、
    呼吸补泻（随病人呼吸进出针）、插提补泻（重插轻提=补、轻插重提=泻）；
    补用阳数（三/五/七/九），泻用阴数；强补强泻=烧山火（补）/透天凉（泻）三进三退；
    另有阳中引阴、阴中引阳、子午捣臼等复合手法。补泻做于原穴/络穴/子穴/母穴/本穴。
  tags: [technique, acupuncture, tonify-disperse]

- id: f16
  title: 模拟法（体表类比取穴）
  type: framework
  source_chapter: 第四章·合阳穴与模拟法
  source_quote: |
    "这叫模拟法……这是不是人字纹。委中从腿下来，脚踮起来时，你可以看到腿肚子有人字纹，人字纹下面就是承山。这个承山刚好跟肛门是对到的。"
  summary: |

    病位（如膀胱经痛）在模拟图上对应点找压痛点下针，一击即中。
    用于背痛残余痛、痔疮等，无固定穴名，以压痛点定位。
  tags: [technique, acupuncture, analogy]

- id: f17
  title: 指针术（小儿推拿框架）
  type: framework
  source_chapter: 第六章·三关：幼儿治症（指针法）、指针术
  source_quote: |
    "三关正常是这样，如果有黑线青筋在上面两个指头都是很好治的……初症……是在风关，没有治好才会到气关……到了命关会有生命危险。"
  summary: |

    眼珠上吊/下吊/斜视用耳轮揉拉（双龙抢珠）调整；小儿黄疸推肝胆筋、吐奶推脾胃筋。

- id: f20
  title: 留针时长决策
  type: framework
  source_chapter: 第六章·灵龟八法与子午流注
  source_quote: |
    "新病，初病留的时间很少，三、五分钟就可以起针了，如果是久病，留二十分钟是基本的。"
  summary: |
    留针管理框架：新病/初病留针 3-5 分钟；久病 20 分钟起，期间每 5 分钟运针做补泻；

    怕针者下针做完补泻后静留亦可。留针期间动针做补泻在原穴/络穴/子母穴/本穴上进行。

# 四诊合参诊断法

> capability: cap.renji-zhenjiu.diagnosis · 来源：《人纪系列·针灸篇》第四、六章

## R — Reading（原文）

> "当用手指头压的时候，如果有心脏病，压第五椎就会痛。肺有问题时，压第三椎就可以感觉出来。"（第四章·膀胱经俞穴）
>
> "眼白的地方……是诊断肺的地方。眼睛内眦……是诊断心脏的地方。……瞳孔都是黑色的，所以查肾脏查瞳孔。"（第四章·眼诊法）
>
> "把耳朵图倒过来时……这个耳朵就像个小baby……这是头（耳垂）嘛……从这边开始就是我们的内脏。"（第六章·耳针治疗）
>
> "脚是热的就没有癌症。你现在还没有癌症，就要想办法把脚热起来。"（第四、六章）

## I — Interpretation（自述）

四诊合参定病位病性的诊断框架——**压痛点 + 眼诊 + 耳针 + 望诊 + 问诊（时辰/大小便/口渴/足温）**：

1. **背俞穴压痛点图谱**（督脉旁开一寸半）：第三椎=肺、第五椎=心、第六椎=督脉（血癌）、第七椎=膈（血）、第九椎=肝、第十椎=胆、第十一椎=脾、第十二椎=胃、第十三椎=三焦、第十四椎=肾。压痛点存在=该脏腑有病；治疗后压痛消失=病愈（诊断与疗效验证合一）。
2. **眼诊五色五脏**：眼白=肺（白块/面包屑样）、内眦=心（红）、瞳孔=肾（照光收缩=肾阳足、不动=阳虚、放大=死兆）、瞳孔外圈=脾（土，1/3 比例、密纹=正常）、最外圈=肝（木，2/3 比例）。
3. **耳针倒置婴儿图**：耳垂=头、耳轮=脊椎、对耳轮=躯干四肢、三角窝=子宫卵巢；圆头探针沿耳廓按压找压痛点=对应部位病变；凸起=实（肿瘤）、凹陷=虚。
4. **望诊辅助**：眼袋暗黑=肾伤、卧蚕凸起=水肿；脸颊赤红蝴蝶斑=心脏营养逆流（狼疮征）；头发枯干不反光=肾气将绝。
5. **问诊关键项**：脚冷=小肠火衰/寒水/下焦有积、脚热=健康；定时发作（时辰）→ 该经问题（3-5 点醒=肺、7-9 点心包、下午 1-3 点累=小肠）；大小便、口渴（寒不渴、热渴饮冷）辨寒热；喜按=虚、拒按=实。

四诊合参：以压痛点为主定位，眼诊耳针望诊辅助定性，问诊定寒热虚实，最后给出"病位归经+病性虚实寒热"结论。

## A1 — Past Application（书中案例）

- **血癌（c05）**：32 岁牙医血癌，第六椎（督俞）压痛点；治疗四周后第六椎压痛消失=病愈——压痛点诊断+疗效验证的完整闭环。
- **红斑性狼疮（c06）**：每次第五椎有压痛点（心），伴便秘、月经不调、失眠；据此治心（心俞+肺俞+肝俞），皮肤红色消退——压痛点+望诊（蝴蝶斑）合参。
- **肺癌前兆（c07）**：连续两年凌晨 3-5 点醒（肺经时辰），第三椎压之痛——时症+压痛点双信号，在影像确诊前两年即可提示风险。

## A2 — Future Trigger（何时用）

**场景**：
1. 用户问"怎么判断病人哪里有问题""压哪个椎代表什么"
2. 用户描述体征（眼袋黑/脸赤红/脚冷/失眠时辰）问属哪脏问题
3. 用户问眼诊/耳针/望诊怎么辨病
4. 用户问"如何判断虚实寒热"（喜按拒按、口渴、大小便）
5. 用户想学自我健康初筛（脚温、压痛点自查）

**语言信号**：怎么诊断 / 压哪里痛 / 眼诊 / 耳针 / 虚实 / 寒热 / 脚冷脚热 / 背俞穴 / 第三椎 / diagnosis / palpation

**与相邻能力区分**：诊断（判病位病性）≠ 选穴（定扎哪）≠ 方案（病→穴）。用户要"诊断结果"→ 本能力；要"怎么治"→ 决策/方案库。

## E — Execution（执行步骤）

1. **收集四诊素材**：问/查压痛点（背俞椎位）、眼部特征（色块/结构/瞳孔反应）、耳廓压痛点、望诊（眼袋/脸色/头发）、问诊（脚温、时辰发作、口渴、大小便、喜按拒按）。
   - 完成标准：至少采集 2 类素材（推荐压痛点+问诊）。
2. **对照图谱定病位**：压痛点椎位→脏腑；眼/耳/望诊特征→对应脏；时辰发作→经络。
   - 完成标准：给出"疑及 X 脏/X 经"的候选。
3. **定病性**：喜按/拒按→虚实；口渴饮水/大小便/难受度→寒热；脚温→阳气/下焦状况。
   - 完成标准：输出"虚/实/寒/热"结论（至少虚实）。
4. **合参输出**：合并多信号（两处以上同指向某脏才下结论；单信号标"疑似"）；给出建议（可转辨证选穴/方案库）。
   - 完成标准：输出"病位归经+病性+证据链+置信度"。

## B — Boundary（边界）

**不要用**：
- 把压痛点/眼诊/耳针当作现代医学确诊手段——这是传统辨证参考，不替代影像/检验/病理。
- 单信号即下确诊结论（须合参，单信号标"疑似"）。
- 对急症（剧烈胸痛、大出血、昏迷）只给诊断不提示就医。
- 把"脚热无癌""心脏不受癌"等作者断言当作科学结论输出（非循证）。

**作者盲点警示**：椎-脏腑/眼-五脏/耳-部位对应为古典模型，诊断特异性未经对照研究验证；作为传统辨证思维与健康初筛使用，不作最终诊断。

**近邻区分**：诊断（判病）≠ 决策（选穴）≠ 安全禁忌（能不能）。

## 相关能力

- **组合**：诊断结论直接作为辨证选穴决策（cap.renji-zhenjiu.dialectical-selection）与治症方案库（cap.renji-zhenjiu.formula-library）的输入。

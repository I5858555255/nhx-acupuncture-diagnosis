## I — Interpretation（自述）

十二正经+任督二脉+奇经八脉穴位参考库。每条穴位按统一结构组织：

1. **定位与找法**：以同身寸（看病人手）+骨度+解剖标志定位；找穴口诀（如足三里=膝眼下三寸、委中=膝后中央横纹、承山=踮脚人字纹下）；"穴在肌肉筋骨之间不在其上"。
2. **主治**：局部病症+远端脏腑病症+特殊用途（如郄穴止痛消炎、井穴急救、俞穴调脏）。
3. **针法深浅**：按部位（腹深似井、背薄似饼）+季节（春浅秋冬深）+体质；头部在头皮与头骨之间、不可入颅。
4. **补泻属性**：井荣俞原经合属性（阴经木火土金水、阳经金水木火土）、本穴/母穴/子穴、原络郄募俞会归属。
5. **禁忌**：禁灸（热/汗处/眼/阴部/头部）、禁针（孕妇腹部、神阙）、危险穴（肩井不可深、背部不可深）。

经络走行速记：肺寅大卯胃辰宫，脾巳心午小未中，申胱酉肾心包戌，亥焦子胆丑肝通（肺经丑时/大肠寅时……按流注时辰）。

## A1 — Past Application（书中案例）

- **养老透间使（c03）**：养老穴在小肠经，屈肘掌心向胸取穴；三寸针养老透间使治手肘痛不能扭毛巾，当场见效——"定位准确+透穴"的范例。
- **委中放血（c04/c10）**：委中在膝后横纹中央，踮脚拍打见青筋；放血针点刺青筋治卡波西肉瘤/皮肤病/尾椎伤——"找法+特殊用法"示范。
- **承山对应肛门（c17）**：踮脚人字纹下找承山，与肛门对应（模拟法），治痔疮/尾椎伤——"找法+对应关系"示范。

## A2 — Future Trigger（何时用）

**场景**：
1. 用户问"某某穴在哪、怎么找"（列缺/足三里/委中/太冲/合谷…）
2. 用户问"某某穴主治什么、针多深、能不能灸"
3. 用户问某条经络（肺经/胃经/胆经…）的循行路线和穴位
4. 用户问五俞穴属性、原络郄募俞会等特殊穴
5. 用户写论文/学习/备课需要核对穴位标准

**语言信号**：XX 穴在哪 / 怎么找 / 主治什么 / 针多深 / 禁灸吗 / 经络循行 / 列缺 足三里 委中 / where is L14 / what does ST36 do

**与相邻能力区分**：查"穴在哪/主治" → 本能力；报病名要方案 → 治症方案库；问"怎么选穴思路" → 辨证选穴决策；问禁忌规则 → 安全禁忌。

## E — Execution（执行步骤）

1. **解析查询对象**：确定要查的穴位/经络/特殊穴类型（五俞/原络/郄募俞会/奇穴）。
2. **输出标准条目**：归经 → 定位（同身寸/骨度/解剖标志）→ 找法（口诀/动作）→ 主治（局部/远端/特殊）→ 针法（深浅、补泻属性）→ 禁忌（禁针禁灸）。
   - 完成标准：六要素齐全；深度按"腹深似井背薄似饼"+季节体质给范围。
3. **关联补遗**：若该穴有特殊身份（本穴/母穴/子穴/郄穴/八会），标注五行属性与补泻意义；若查询经络，给出流注时辰+气血走向+循行概要。
   - 完成标准：特殊身份标注完整。
4. **安全提示**：凡属危险穴（肩井、背部俞穴、眼周、颈项），附明确警示。

## B — Boundary（边界）

**不要用**：
- 把"穴在哪"的回答当成"病怎么治"的方案输出——知识库只提供穴位数据，取穴决策走辨证选穴/治症方案库。
- 输出未核实的穴名/归经/主治——本书内容与《针灸大成》《甲乙经》同源，但个别表述为倪氏个人用法（如阴经以输为原、心包经某些定位），引用时注明"按倪氏体系"。
- 忽略禁忌：查到的禁灸/禁针穴必须在输出中保留警示。

**作者盲点警示**：部分穴位的特殊功效主张（如"委中解毒治AIDS表证"）为作者临床叙述，非循证结论；定位与主治作为传统针灸参考使用，不替代影像/检验诊断。

**近邻区分**：知识库（穴数据）≠ 方案库（病→穴组合）≠ 诊断（体征→病位）。

## 相关能力

- **组合**：为辨证选穴决策（cap.renji-zhenjiu.dialectical-selection）与治症方案库（cap.renji-zhenjiu.formula-library）提供定位/主治数据。

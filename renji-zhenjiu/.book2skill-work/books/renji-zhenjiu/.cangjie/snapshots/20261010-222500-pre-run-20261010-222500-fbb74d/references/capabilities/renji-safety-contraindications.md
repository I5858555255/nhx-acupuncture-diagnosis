# 针灸安全禁忌与操作规范

> capability: cap.renji-zhenjiu.safety-contraindications · 来源：《人纪系列·针灸篇》第一、二、五、六章

## R — Reading（原文）

> "针就是针，灸就是灸……有一个歌诀：'针而勿灸灸勿针，针经为此常叮咛。庸医针灸一齐施，徒施患者炮烙刑。'"（第一章）
>
> "遇到气血大虚、重病、刚刚失过很多血、病患完全没有元气的时候，这时候我们不下针。另外，刚做完爱，行完房事后，也不针。……喝酒后，不针。体力不够，不下针。"（第一章）
>
> "一般热症不用灸法。……流汗多的地方不灸……眼睛不要灸，阴部不灸。"（第一章）
>
> "女人在怀孕的时候，腹部有些穴道是不针的，因为怕有问题。合谷、三阴交也不针。"（第六章·怀孕忌针）

## I — Interpretation（自述）

针灸操作的安全底线清单，**任何取穴方案之前必须检查**：

1. **不下针时机（p02）**：气血大虚/重病/失血过多/无元气、行房后、运动大汗后、酒后、体力不够——均不下针。
2. **不灸时机（p03）**：热症（发烧）、流汗多处（手掌）、津液多处、眼睛、阴部、头部（发根）、面部、委中（汗多）、痔疮（已热）。灸=久+火，用于寒证与针力不足处。
3. **针灸分离（p01）**：针而勿灸灸勿针，不在同一穴道混用（反对温针灸滥用）。
4. **禁针部位**：孕妇腹部、合谷/三阴交（孕期）、神阙（禁针禁灸）、背部不可深刺（背薄似饼）、头部在头皮与头骨之间、眼周须直进直出（防出血）。
5. **深浅规范（p09）**：腹深似井（可深）、背薄似饼（不可深，防伤肺）；深浅随季节（春浅秋冬深）、病位（皮毛-肺/肌肉-脾/血脉-心/骨-肾）、体质（胖瘦）变化。
6. **火罐禁忌（p17）**：乳中禁罐（乳头流黄水）、多汗处禁罐、头部禁罐。
7. **操作规范**：同身寸看病人手（p08）；穴在肌肉筋骨之间不在其上（p07）；起针直进直出防出血（p10）；灸单数不灸双数（阳数，p04）；痛灸到不痛、不痛灸到痛（p05）；灸膏肓后必灸足三里导气下行（p22）；留针新病 3-5 分、久病 20 分起（p18）。
8. **孕妇特殊（p16）**：补合谷+泻三阴交=堕胎（禁），泻合谷+补三阴交=安胎；孕期腹部禁针；安胎可灸隐白/三阴交，胎位不正针至阴，孕吐下公孙内关。

## A1 — Past Application（书中案例）

- **膏肓痛放血（c11）**：膏肓痛用下针/俞募/子母补泻均无效，必须放血（肩胛骨打开后点刺+火罐吸血）当场愈——"病位决定治法"而非套用常规。
- **灸后水泡处理**：灸起水泡用消毒针从旁刺小孔慢按排水+撒硫磺大黄粉，禁止撕皮（防留疤感染）。
- **频尿灸中极关元（c13）**：八九十岁频尿，灸中极/关元把小肠火救起，水气化则膀胱括约肌恢复——灸法用于虚寒的成功示范。

## A2 — Future Trigger（何时用）

**场景**：
1. 用户问"这个穴/部位能不能灸、能不能针"
2. 用户问"孕妇/生理期能不能针灸""有什么禁忌"
3. 用户问"留针多久、怎么起针、灸后水泡怎么办"
4. 用户问"针灸安全吗、有什么风险"
5. 用户准备施针前要求核查禁忌

**语言信号**：禁忌 / 禁针 / 禁灸 / 孕妇能针灸吗 / 留针多久 / 起针 / 水泡 / 火罐 / 深浅 / 安全 / contraindication / safe to needle

**与相邻能力区分**：禁忌（能不能/怎么操作）≠ 方案（怎么治）≠ 选穴（扎哪）。所有针刺类回答都应先过本能力的安全检查。

## E — Execution（执行步骤）

1. **解析操作对象**：确认是什么操作（针/灸/火罐/放血）、什么部位、什么人（孕妇/儿童/老人/虚弱者）、什么状态（酒后/大汗/房事后/大虚）。
   - 完成标准：四要素齐全。
2. **逐条比对禁忌**（判停点：命中任何禁条 → 直接给出"禁止+原因+替代建议"，不进入下一步）：
   - 针：大虚/酒后/大汗/房后/体力不足 → 不下针；孕妇腹部/合谷/三阴交 → 禁针。
   - 灸：热症/汗处/眼/阴/头部/面部 → 禁灸。
   - 罐：乳中/多汗处/头部 → 禁罐。
   - 深浅：背部/肩井 → 禁深刺；头部 → 头皮头骨之间。
   - 完成标准：无禁条或已标红。
3. **输出操作规范**：同身寸度量、穴在缝中找法、直进直出起针、灸壮数（单数）、灸边界（痛灸到不痛）、留针时长、灸后导气（足三里）。
4. **给出安全提示**：属专业操作须执业医师执行；出现异常（晕针、出血不止、剧痛）的应急处理方向。

## B — Boundary（边界）

**不要用**：
- 本能力不替代禁忌咨询后的治疗决策——只给安全规范，不给"违反禁忌的例外方案"。
- 对"自己在家施针"的请求：明确提示必须由执业医师操作（放血/深刺/灸百壮属专业行为）。
- 把作者"疫苗无用""化疗阴阳分隔"等立场断言当安全依据输出（非循证，ce07/ce06）。

**作者盲点警示**：部分禁忌细节（如"补合谷泻三阴交堕胎"）为传统经验传承，缺乏现代循证复核；作为传统操作规范参考，孕妇等敏感人群的医疗决策以执业医师+现代指南为准。

**近邻区分**：安全禁忌（能不能）≠ 急救（怎么办）≠ 选穴（扎哪）。

## 相关能力

- **组合**：作为所有针刺类能力的前置检查——辨证选穴（cap.renji-zhenjiu.dialectical-selection）、治症方案（cap.renji-zhenjiu.formula-library）、急救针法（cap.renji-zhenjiu.emergency-special）、小儿指针（cap.renji-zhenjiu.pediatric-wellness）施针前均须过本能力。
- **依赖**：急救与特殊针法中的高风险操作（放血/深刺）必须先核对本能力禁忌。

## 5. 结论

1. **两项通过"ΔTP≥0 且 ΔFP≤0"门禁（可作为首批候选）**
   - `PB-C2`（M2-06 太冲条件化）：恢复期删太冲，**ΔFP −7、ΔTP 0**，F1 +0.30pp（核心 64 +0.30pp、复诊 +0.47pp）。
   - `PB-C3`（肺积水恢复期补脾胃，加足三里）：**ΔTP +7、ΔFP 0**，F1 +0.49pp（核心 64 +0.47pp）。
   - 二者合并（组合A）：**ΔTP +7 / ΔFP −7 / ΔF1 +0.80pp（核心 64 +0.78pp）**，且副作用案为 0。这是本批**最干净、可优先工程化**的证据。
2. **`PB-C1b` 是最强的 FP 杠杆，但因损 recall 未过门禁**
   - 八脉交会层 160 点中仅 51 中金标准（≈109 FP）；按证候分流并保留已登记规则适应症后，**ΔFP −17 且仅 ΔTP −1**（唯一副作用案 `221_01` 的后溪+申脉），F1 +0.54pp、核心 64 +0.63pp。
   - 未过门禁的原因就是那 1 个 TP：**须先人工核定 `221_01` 后溪+申脉 的原书依据**（若属"项背/督脉"证据而输入未显式表达，应把该证据词补入闸门；若属误取，则本候选完全干净）。
3. **`PB-C7/C7b` 收益最大但"提升不落在核心集"**
   - C7b：**ΔTP +14 / ΔFP +2**，86 案 F1 +1.12pp；但**核心 64 ΔF1 为 −0.0009**——因为收益集中在 `67_01…74_01` 乳癌链的**复诊跟随案**，而这些案已被审计判为"天然不可开"并**排除出核心 64**。
   - 值得注意的正面发现：这些复诊案的输入 `既往就诊及治疗反馈` 字段实际携带"手後三指麻，心包最麻"等证据，**所以"手麻分经"类规则在其中是可触发的**——"天然不可开"结论主要针对"整段继承处方"，并不否定个别可触发规则。
   - 因此 C7 应作为**复诊层（含被排除案）**的改善项单列，不得用来宣称核心集提升。
4. **`PB-C6`（R7a 外踝胆经）应放弃**
   - 即便加"踝部肿痛"收缩闸门，仍 **ΔF1 −0.56pp**（首诊 −1.69pp），与 M9-C2"需收缩"一致但更严：**收缩后仍为负收益**。建议终止该方向。
5. **`PB-C4` 待定**：+3 TP / +2 FP（`13_01`、`70_01` 各 +1 FP），需更严闸门或人工核 阴谷 适应症。

## 6. 方法学限制（必须随结论一并引用）

1. **预测级 = 上界估计，非盲法结论。** 本批在冻结预测上做反事实消融，**未重跑盲法**；工程化后必须经盲法回归确认，且不得据本批数字登记为正式指标。
2. **部分 gold 信息泄漏（已如实声明）**：`PB-C2/PB-C3` 的"急性边界 = 140_01/142_01"来自 `C_残余归因`，其源头是**原案处方记录**；真正实现时必须改为**纯输入信号**判定急性/恢复期（现输入关键词不足以稳定区分，见 P-A §5 同源问题）。`PB-C1b` 闸门中"保留已登记规则适应症"取自本案预测的 `依据` 字段，属规则侧信号，不构成泄漏。
3. **未做跨链留出（M9 式）**：本批为全集内消融，未做 leave-one-chain-out 复核；链级泛化性未验证。
4. **未做规则实现**：候选仍是"预测级操作描述"，尚未写成可执行规则条文，也未评估与 M2 条目的优先级/交互冲突（除 C2/C3 属 M2-06 内部细化、C7 属 M2-03 延伸）。

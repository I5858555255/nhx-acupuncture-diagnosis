## 1. 逐案审查

### 1.1 案 `160_01`（链 `S_160_01`）——列缺+照海（**低风险·删除可接受**）

- **关键症情**（原文节录）：白血病，白血球由八萬多降至七萬多；小便緊急、次數多、量少；**雙足溫熱**；大便很好；胃口好；**口渴喜熱飲**；**早起口乾苦**；體力精神很好。
- **v14r5 主穴**：少海、膈俞、血海、三阴交、间使、督俞、**列缺+照海**（八脉层）。
- **依据**：「八脉交会主配治喉胸；早起口干苦」。
- **命中机制**：v15 命中＝`乾`（来自「早起口**乾**苦」）；v16 命中＝**无**（从零表 列缺+照海＝喉/咽）。
- **gold**：三阴交、中极、关元、地机、心俞、水道、督俞、肝俞、肺俞、阴陵泉（**不含列缺/照海**）。
- **裁决**：**删除可接受（低风险）**。
  - 「口干苦」的「干」是**口**干（mouth），而列缺/照海的原书主治是**喉**病/咽（throat）。严格按原书，`乾`（口干）**不属**该单元本穴主治 → 删除站得住。
  - 保留意见：若采「口干≈咽干」之宽解，照海（肾经/阴跷，主咽干）可被保留；此项列为**已知边界**，不构成必须保留的理由（gold 亦未取）。

### 1.2 案 `207_01`（链 `S_207_01`）——列缺+照海（**低风险·删除正确**）

- **关键症情**（原文节录）：右足踝扭伤后外踝易酸痛；**失眠**（半夜2-3點醒）；右手腕痛（媽媽手）；**鼻塞**；大便每日2次常软；雙足冷；月經準時；掉发；**眼診：肝區…黑點；肺區有痰淡紅有牙痕**。
- **v14r5 主穴**：行间、迎香透内迎香、养老透间使、丘墟、侠溪、**列缺+照海**、肝关。
- **依据**：「特效库治鼻病条 diag肺开窍于鼻 鼻病从肺治 兼甲状腺条 plan远取照海列缺」。

  - v15 的保留靠**眼诊文本里的"肺"字**机械命中，**不是**一个临床症状指征 → 属**关键词误命中**，删除反而更合理。
  - 注：`列缺`单穴用于鼻塞（肺开窍于鼻）在临床上可辩，但本案 v14r5 出的是**"列缺+照海"配对单元**，而**照海於鼻无据**；且 gold 未取 → 删除站得住。

### 1.3 案 `303_01`（链 `S_303_01`）——列缺（**中风险·真实过度删除**）

- **关键症情**（原文节录）：16 岁男，**自小過敏**；**皮膚因使用類固醇藥物，造成很乾燥、粗**；**身上多處皮膚乾皺紅赤**；**氣候變時紅疹明顯**；半夜盜汗；小便多(10次)；口渴無；自覺熱；**雙足冷**；眼診：瞳孔收縮不佳(腎陽不足)、心區扁平(心陽不足)、右眼肺區上方灰濁(痰濁)。
- **v14r5 主穴**：合谷、曲池、委中、**列缺**、血海、三阴交、**照海**（八脉层两单元）。
- **依据**：
  - `列缺`：「**肺经络穴**/八脉交会通任脉**利皮肤**（指南6.4；特效库9条**肺主皮毛**）」
  - `照海`：「肾经/八脉交会配列缺治喉胸二便（指南6.4；知识条目L1860照海）」
- **命中机制**：
  - `列缺`：v15 命中＝`肺`、`皮`（`皮` 来自「**皮**膚…乾燥粗」）；v16 命中＝**无** → **删除**。
  - `照海`：v15 命中＝`便`、`乾`；v16 命中＝`便`（从零表含 便）→ **保留**（未删）。

- **裁决**：**真实过度删除（中风险）** —— 仅限 `列缺`。
  - 该案 `列缺` 的**依据链本身**（肺经络穴 + 肺主皮毛 → 利皮肤）是**原书明载**的皮肤病治法（教程 L684／特效库 L156），且**症状原文含「皮膚…乾燥、粗」**（关键词 `皮` 为**真实症状命中**，非眼诊伪命中）。
  - 因此 v15 的保留**机制正当**；v16 因「从零表」只收列缺本穴主治（喉/咽/任/陰），**漏掉了"肺经络穴"这一原书支持的皮肤间接指征** → 属**系统性缺口**。
  - `照海` 在本案被保留（`便`），**无过度删除**。

## 3. 结论与建议

1. **三案中仅 1 案构成真实过度删除**：`303_01` 的 `列缺`（皮肤/肺主皮毛，原书明载 + 真实症状词 `皮`）。
2. `207_01` 的删除**正确**（v15 靠眼诊"肺"字伪命中）；`160_01` 的删除**可接受**（口干 ≠ 喉/咽，属已知边界）。
3. **建议（推荐）：提案-003 微修** —— 在从零表为 `列缺` 增补 `皮`（原书：教程 L684／特效库 L156／指南 L282「肺主皮毛，皮肤病在肺上治」＋列缺为肺经络穴），得到 **`v16′ = +0/−17/+0.0048`**：
   - 消除唯一的真实过度删除；
   - 仍优于 v15（`+0.0038`）；
   - `207_01`（伪命中）与 `160_01`（口干边界）保持删除。
4. **若采纳**：须经用户批准后执行（HARD-05/06，本审查与提案均**不自动合入**）。备选：直接维持 v16（严格原书口径），并把 `303_01` 登记为**已知可接受的过度删除**。

## 4. 诚实声明与局限

- 本审查为**规则级/文本级**的临床正当性论证，**不是**临床医生盲审；「站得住」系依原书条文 + 症状文本的**可溯性**判定。

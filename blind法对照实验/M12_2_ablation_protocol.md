1. **隔离分支/离线副本**：候选副本只在本地工作目录创建临时副本（如 `tmp_ablate_M12_2/`），不提交、不推送；正式目录一律只读（HARD-01、HARD-05）。

## 4. 执行步骤

1. **Diff 两版规则**：对比 v14r2 与 v14r5 两版技能，列出所有规则文本差异；预期仅剩一条 M12-2 优先级注释（若差异更多，则 M12-2 的假设需重新评估，本方案终止）。
2. **构造 v14r2+（无 M12-2）候选**：在隔离副本中回退该一条注释，保留其余全部规则。
3. **复跑盲法评估**：使用既有脚本（`blind法对照实验/benchmark_v2/` 下的 `gold_parse93v2.py`、`score_benchmark_v2.py`）在两个候选（v14r2+ 与 v14r5）间运行相同数据集；输出到隔离目录。
4. **对照基线指标**：汇总 Precision/Recall/F1/Jaccard（86 案宏平均），与 v14r5 正式基线登记值比较；任何指标变化必须如实记录，不得调整定义。
5. **判定**：
   - 仅 M12-2 差异且 v14r2+ 与 v14r5 指标持平（或仅 M12-2 带来预期收益）→ 假设成立，记录为 P3 结论。
   - v14r2+ 与 v14r5 指标显著差异 → 假设不成立，须另行做消融解释（候选回退组合）。
6. **产出**：写入隔离目录的评审报告（含命令日志、判分明细）；不合入正式基线登记（需用户确认）。

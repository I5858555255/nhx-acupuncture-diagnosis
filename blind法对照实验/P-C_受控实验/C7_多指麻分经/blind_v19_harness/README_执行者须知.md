# 执行者须知（一页纸）

你被要求执行一次**盲法回归测试**：按一套针灸技能，对 86 个真实就诊记录逐个给出主穴处方。这是一次**测量**，不是调优——请如实输出，不要猜"标准答案"。

## 你要做的三件事

1. **装技能**：把 `skill/doubao-acupuncture-diagnosis/` **整个目录**复制到你的 skills 根目录，保持目录名不变：
   - OpenCode：`~/.config/opencode/skills/doubao-acupuncture-diagnosis/`
   - Claude Code 等同一约定：`~/.claude/skills/doubao-acupuncture-diagnosis/`
   - 复制后确认 `SKILL.md` 在目录根部、`references/` 存在、`SKILL.md` 里含 `**v19 变更基线**`。
2. **逐案跑**：按 `run_plan.json` 的分片顺序，把 `prompts/*.txt` **一个文件一次调用**发出去（每案新开上下文）。把回复里的 JSON 存成 `runs/<case_id>.json`。
3. **回传**：把整个 `runs/` 目录压缩回传。不要做任何汇总、改写、挑案。

## 绝对不要做

- ❌ 不要访问本测试包以外的任何目录（尤其不要去找 "nhx" 仓库、`blind法对照实验/`、`盲法对照实验/`）。
- ❌ 不要联网搜本案或任何"标准处方"。
- ❌ 不要读技能里的 `references/典型案例示范集.md`（技能本身规定盲测禁用）。
- ❌ 不要跨案记忆；不要因为觉得"上一个案类似"就照抄。
- ❌ 不要修改已落盘的输出，不要"跑到满意为止"。

## 只允许的一个跨案信息

`prompts/` 里会写「上一诊案号」。如果该案在**同一片**里、你已经跑过，就把你**当时输出的 `主穴` 数组**原样填进本案的 `上游_上一诊主穴` 字段；否则填 `null`。是否采用它，由技能规则决定，你不用判断。

## 输出格式

严格按 prompt 末尾的 JSON schema。评分**只看 `主穴` 字段**：

- 单穴写穴名（`太渊`）；成对/透刺写 `A+B`（`合谷+太冲`）。
- 只写针刺主穴；灸位、备选、随访建议放 `临床参考建议`。

## 如果某案做不了

输出 `{"case_id":"...","status":"SKIPPED","reason":"..."}`。**不要编造**——缺案的批次会被评分器整批拒收。

## 规模与预估

86 案，分 5 片（13–18 案/片）。每案都是完整流程（问诊→望诊→触诊→辨证→四层选穴→反查→复检），请预留足够时间；宁可慢，不要压缩成"模板套用"。

# 执行者须知（A-2 臂，一页纸）

这是一次**盲法回归测试的拆分臂**：只跑 **25 个复诊/延续案**，用于测量"**没有上一诊信息**时技能能走到什么水平"。同一批病例的另外 61 案已在另一臂跑过，**不需要你重跑**。

## 你要做的三件事

1. **装技能**：把 `skill/doubao-acupuncture-diagnosis/` **整个目录**复制到你的 skills 根目录，保持目录名不变：
   - OpenCode：`~/.config/opencode/skills/doubao-acupuncture-diagnosis/`
   - Claude Code 等同一约定：`~/.claude/skills/doubao-acupuncture-diagnosis/`
   - 复制后确认 `SKILL.md` 在目录根部、`references/` 存在、`SKILL.md` 里含 `**v19 变更基线**`。
2. **逐案跑**：按 `run_plan.json`，把 `prompts/*.txt` **一个文件一次调用**发出去（每案新开上下文）。把回复里的 JSON 存成 `runs/<case_id>.json`。
3. **回传**：把整个 `runs/` 目录压缩回传。不要汇总、不要改写、不要挑案。

## 与 A-1 臂的唯一差别

**本臂不提供任何上游/上一诊信息。** 输出里 `上游_上一诊主穴` 一律填 `null`，`上游是否被采用` 一律填 `false`。
即使原文出现"同前穴/同前/如前"等延续表述，也请按本案自身证据推断，**不要假定你知道上次用了什么穴**。

## 绝对不要做

- ❌ 不要访问本测试包以外的任何目录（尤其不要去找 "nhx" 仓库、`blind法对照实验/`、`盲法对照实验/`）。
- ❌ 不要联网搜本案或任何"标准处方"。
- ❌ 不要读技能里的 `references/典型案例示范集.md`（技能本身规定盲测禁用）。
- ❌ 不要跨案记忆；不要因为觉得"上一个案类似"就照抄。
- ❌ 不要修改已落盘的输出，不要"跑到满意为止"。

## 输出格式

严格按 prompt 末尾的 JSON schema。评分**只看 `主穴` 字段**：单穴写穴名（`太渊`），成对/透刺写 `A+B`（`合谷+太冲`）。只写针刺主穴；灸位、备选、随访建议放 `临床参考建议`。

## 如果某案做不了

输出 `{"case_id":"...","status":"SKIPPED","reason":"..."}`。**不要编造**——缺案的批次会被整批拒收。

## 规模

25 案，分 3 片（12 / 7 / 6）。每案都是完整流程，请预留足够时间；宁可慢，不要压缩成模板套用。

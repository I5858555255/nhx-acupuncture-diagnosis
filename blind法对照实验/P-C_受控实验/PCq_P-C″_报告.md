## 1. `221_01` 核定（C1b 唯一副作用案的根因）

### 1.1 事实

| 项 | 值 |

| 盲法输入（关键） | 來診原因「右足跟仍有一點痛。右膝痛，不能久立。**右腰痛**。」；睡至 12PM–12:30PM 醒；舌淡黃濕；脈緩有力 |
| v14r5 主穴 | 束骨、委中、太溪、**后溪**、膝五针、水泉、**申脉**、大陵（八脉交会层 = 后溪、申脉） |
| v14r5 依据 | 后溪=「八脉交会**通督脉利腰背**」；申脉=「膀胱经/八脉交会**配后溪治颈项肩背**」 |

| C1b 行为 | 删 后溪 + 申脉 → **TP −1（误删申脉）、FP −1** |

### 1.2 原书依据

| 穴 | 原文 | 行号 |
|---|---|---|
| 申脉 | 「**阳蹻脉起于跟中**，从外踝裸上来。申脉在管阳蹻」 | 教程_utf8 L3955 |
| 申脉 | 「申脉是在**膀胱经**上面，同时也主阳蹻」 | L3687 |
| 后溪 | 「当病人说，他整个**脊椎骨痛**。一看是督脉，就下后溪」 | L2457 |
| 后溪 | 「如果有病人…**背痛**，且痛在**督脉**上面，我们知道要扎后溪」 | L3107 |

### 1.3 核定结论

1. **申脉为误删。** 申脉 = 足太阳膀胱经腧穴 + 阳跷脉起点（原书明言「起于跟中」），其适应症覆盖**腰背 / 下肢外侧 / 足跟**；本案输入含「右腰痛 + 右足跟痛」→ **适应症成立**。v14r5 把它记成"配后溪治颈项肩背"是**依据标注不全**（漏了膀胱经/阳跷一族），**不是取穴错误**。
2. **后溪亦为误删（按 C1b 自身原则）。** 后溪「通督脉利腰背」，输入有「右腰痛」→ 适应症成立；虽原案未取（属 FP），但 C1b 的原则是"**保留已登记适应症**"，故应保留。
3. **根因 = 闸门关键词表不全**：`后溪` 闸门 `項/頸/背/督/肩`、`申脉` 闸门 `項/頸/背/蹺`——**均漏「腰」**（督脉、膀胱经、阳跷皆循行腰背），`申脉` 另漏「跟/踝/膀胱/阳跷/太阳/下肢/足外」。本案输入用「**腰**」而非「背」，故被误删。

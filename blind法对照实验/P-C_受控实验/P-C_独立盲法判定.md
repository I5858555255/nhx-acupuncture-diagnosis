## 3. 结论（本记录的核心）

1. **候选规则的"急性 / 恢复期"闸门无法由输入稳定判定**：独立执行者与登记分期在 **5/9 案**上分歧。
2. 分歧方向不是单一的（既有把登记"恢复"判为"急性"的，也有把登记"急性"判为"恢复"的），说明**不是执行者保守/激进偏差，而是判据本身欠定义**——现有输入里的"水肿是否退"多为主观描述（"仍腫"/"持續往下退"/"向上且更大"），缺少可机读的判据。
3. 因此：受控 patch 重跑 A 的 **+7 TP / −7 FP** 收益**依赖含 gold 信息的分期**；换成独立可判定的分期后（重跑 B）收益降到 **+2 TP / −2 FP**（见 `P-C_受控实验报告.md` §3）。这是本批**最重要的负面证据**。
4. 交付建议：**本候选规则不得按现状合入**；须先把分期判据写成**输入可观察的显式信号清单**（正向："水開始退 / 持續往下退 / 可平躺 / 雙足溫"；负向："仍腫 / 未退 / 須坐起睡 / 腫向上"），并**用独立执行者复核一致性**后再评估。

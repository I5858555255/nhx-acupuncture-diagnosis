## 候选 A · 八脉交会分流（M2-04 / M2-05 / R2 语境）

**拟插入位置**：`SKILL.md` 八脉交会相关系目之后（M2-04、M2-05、R2 分型块相邻处），作为独立"分流子规则"。
**优先级**：**低于**主证整组（M2-01 肩髃组 / M2-05 心脏三针组 / M2-06 利水组）；只作用于**八脉交会层**单元，不改对症 / 俞募背俞 / 特效奇穴层。

```markdown
**★ 候选·八脉交会分流（M2-04/M2-05/R2 语境）**：八脉交会层单元（"公孙+内关"、"外关+足临泣"、"后溪+申脉"、"列缺+照海" 等）**仅当**其"本单元证候关键词"或"其依据所指已登记规则的适应症关键词"在**本次输入全文**中命中时，方保留于**主穴**；否则该单元**降入"临床参考建议"**（降级，不废除）。
- **本单元证候关键词（节录；全表见 `候选规则_条文化.json`）**：
  - 公孙+内关 → 心/胸/悶/胃/脘/腹/嘔/悸/咳/喘
  - 外关+足临泣 → 耳/目/眥/眼/偏頭/脅/頸/肩
  - **后溪+申脉、后溪 → 項/頸/背/督/肩/**腰/脊
  - **申脉 → 項/頸/背/蹺/**腰/脊/跟/踝/陽蹻/太陽/膀胱/下肢/足外
  - 列缺+照海 → 喉/咽/胸/膈/肺/咳/乾
- **已登记规则适应症追加**：依据含 `M2-04`／腋 → 追加 腋/淋巴/乳；依据含 `R2`／`M2-05`／心脏条 → 追加 脈/結代/悸/數/冷/水腫/積水/心陽。
- **排除**："合谷+太冲"（层标签虽为八脉交会，实为开四关，不纳入本分流）。
依据=教程_utf8 L3955「**阳蹻脉起于跟中**」、L3687「申脉是在**膀胱经**上面」、L2457/L3107「后溪…督脉…脊椎/背痛」；由 P-C″ `221_01` 核定补入「腰/脊/跟/踝/膀胱/阳跷/太阳/下肢/足外」。
```

> **已登记规则不被收窄废除**：本案该单元若属 M2-04（两腋淋巴半表半里）、M2-05/R2（心胸心律、肺积水）等**已登记规则的证据组**，其题内关键词已并入上表，故仍在主穴保留。

## 候选 B · R2/M2-06 病程分期（恢复期 去太冲 / 补足三里）

**拟插入位置**：`SKILL.md` 第 80–83 行 R2 肺积水亚型分流块内（"互斥闸门"之后、"与 C3 交互"之前）。
**优先级**：**低于** R2 分型闸门（先分型、后分期）；不改变 M2-05 心脏三针组。

```markdown
**★ 候选·R2/M2-06 病程分期（候选·未合入）**
- **适用前提（硬约束）**：**仅当本案 R2 肺积水亚型分流已触发**（心肾阳虚型 / 胸肋积水型）时启用；非 R2 触发案一律不适用。**缺此前提，本闸门会在无关案上过触发**（见复核 §3）。
- **判定顺序**：
  1. **负向关键词**（水未退/上泛）经"非假设句判据"过滤后**任一命中 → 急性期**：
     `仍水腫 / 仍有水腫 / 仍腫 / 未退 / 水腫未退 / 腫向上 / 腫更大 / 腫上去 / 向上且腫 / 須坐起 / 須要坐起 / 坐起睡 / 仍有積水 / 肺中仍有積水`
     **非假设句判据**：负向词所在子句（以 `。；，、（）()：:` 切分）若含 `若/如果/假如/萬一/否則/再/怕/死症/危險/麻煩/加重`，该命中共用**不采纳**。
  2. 否则**强正向关键词**任一命中 → **恢复期**：
     `水開始退 / 水退 / 持續往下退 / 往下退 / 向下退 / 可平躺 / 能平躺 / 可以平躺 / 比以前溫 / 較溫 / 心陽回頭`
     （**词表修订**：**删除过泛词 `足溫 / 雙足溫`**——绝对温度属常见良性体征，特异性差；实测可把全案误触发由 36 案降至 4 案，而 140 链内结果不变。）
  3. **弱正向关键词不足以单独触发**：`好轉中 / 水腫好轉 / 小便增加 / 四逆冷漸少 / 精神好 / 手足不麻`。
  4. 皆未命中 → **无法判定 → 维持基线（不修改）**。
- **动作**：**急性期**＝保留太冲、不取足三里；**恢复期**＝**去太冲**（冲逆已平，不宜再引下）、**补足三里**（胃经本穴属土，灸之强土；利水后转补脾胃，"土制水"），**总量维持 8 穴**（去太冲腾出 1 席后补足三里）。
依据=教程_utf8 L4065「再扎足三里，胃口会开嘛…灸足三里可以强土」；L4529「（治水/强脾）那足三里，是很好选的穴道」；L4395「遇到任何的重病，一定要先强他的胃气…下中脘、足三里」；L4739「水腫…针三皇穴及太冲」（急性期用太冲）。
```

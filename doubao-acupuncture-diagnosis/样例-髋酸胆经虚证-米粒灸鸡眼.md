> **用途**：`doubao-acupuncture-diagnosis` skill 的验收样例。

## 一、病例摘要（采集壳导出）

- **就诊时间**：2026/09/30 14:39（日柱丁未 · 时柱丁未 · 阴日；未时小肠当令）
- **灵龟八法（现时）**：坤宫 · 主穴照海（阴蹻脉）· 配穴列缺
- **主诉部位**：臀 / 髋，能明确指出位置；阿是压痛居髎
- **伴随症状**：咳喘 / 鼻塞 / 皮毛 / 声音变、关节酸痛 / 麻木 / 屈伸不利
- **性质**：只酸不痛、喜按（虚）；病程超过一个月（久病）
- **问诊**：胃口正常；口渴；大便溏软（不成形·湿）；小便黄赤（热）；盗汗；男性；诱因过劳 / 房事过度
- **望诊**：面色黄（脾）；瞳孔遇光即缩（肾阳正常）；脚冷尤夜；眼袋暗黑（肾病）；眼袋隆起如卧蚕（水肿）；口中异常味
- **触诊**：太溪/冲阳/太冲/合谷/人迎五脉皆存；本经循行上有最明显阿是压痛点
- **其他**：右脚四五趾间足底长鸡眼，米粒灸多次无果
- **病进病退**：病进 · 由四肢末梢往身上走（方错须重议）

## 二、辨证结论

**主病经 = 足少阳胆经（虚）；病本在脾肾（阳虚为主、兼阴虚），标在肺（气虚）与肝（血不养筋）；阴阳两虚、上热下寒、夹湿。**

| 信号（出处） | 指向 |
|---|---|
| 臀/髋只酸不痛、喜按、逾月 → 纯虚（指南5.2、2.3；4.6喜按=虚） | 虚证→补母穴 |
| 阿是压痛居髎 → 居髎痛属胆经（指南6.1路径A/C；知识条目L2273） | 主病经=胆经 |
| 鸡眼在右足四五趾间，正当胆经末梢 | 胆经病起于末梢 |
| 病进由四肢末梢往身上走 → 单纯米粒灸局部未截断病势，方错须重议（指南3.6） | 须以补虚为本重拟 |
| 咳喘/鼻塞/皮毛/声音变 → 肺主皮毛（指南5.6）；口中金属味→味主秋、治合穴（指南6.3） | 肺气虚（补母太渊，尺泽虚证禁用——L671） |
| 大便溏软+面黄+口甜 → 脾虚湿盛（指南3.4黄主脾） | 脾虚夹湿 |
| 小便黄赤+口渴+盗汗，合水肿、溏便 → 肾不化津、小肠火弱水津不布（L378、L1825） | 阳虚为本、虚热为标 |
| 脚冷尤夜+眼袋暗黑+房事过度+过劳 → 肾虚（指南3.1、3.5） | 肾阳肾精亏虚 |
| 瞳孔遇光即缩、五脉皆存 → 脏气皆存、可治（指南3.1、4.1） | 预后可 |

## 三、选经选穴

### 主穴（必取）

| 穴 | 定位与操作要点 | 依据 |
|---|---|---|
| **侠溪**（胆经母穴）双侧 | 第4、5跖骨交接高骨下方；自侠溪上五分进针、沿经向趾端斜刺（顺经为补）；浅刺0.3-0.5寸 | 虚补母（指南6.2）；L2337-2338 |
| **居髎**（阿是）患侧 | 章门直下约八寸半、肌肉与骨之间；1.5-2寸；虚证补法 | 指南4.2；L2273 |
| **环跳**（髋部要穴）患侧 | 腿弯起、摸大腿骨尽端拇指尖到处；三寸针扎至骨头旁关节处；呼吸补泻补法（吸气拔至皮层不拔离、吐气推回，连三下）；一般不留针 | L2274-2276 |
| **阳陵泉**（筋会）双侧 | 腓骨小头前下凹陷；1-1.5寸；补法 | 筋会治屈伸不利（指南6.4八会） |

### 佐穴（备选，取 1-2 个即可，不必全扎）

- **复溜**（肾经母穴）：太溪直上二寸；沿经斜刺转针为补；**灸复溜可温脚**→对脚冷尤夜（L1877-1880）
- **三阴交**（三皇）：内踝上三寸胫骨后缘、勿贴骨膜；祛湿消肿（L1189-1210）
- **太渊**（肺经母穴）：寸口脉上，一寸针斜刺、**先拨动脉**；针向大拇指方向（顺经）为补→对咳喘肺虚（L692、L708-710）
- **中府＋肺俞**（俞募治肺）：咳喘鼻塞重时加；背部斜刺（指南6.4；L1556-1560）
- **肾俞＋京门**（俞募补肾）：脚冷、眼袋黑重时加（L1649、L2252）
- **阴郄**（心经郄穴）：神门上半寸；盗汗备选（L1328）

### 兼病经（识别、不专扎，随症加减）

肝（筋失养·麻木屈伸不利——阳陵泉已代）、心（盗汗——阴郄备选）、小肠（溏便/脚冷——关元灸已代）

### 五行治未病（必出，指南5.4）

- **胆（木）病 → 强脾防木克土**：**足三里、太白、章门**（必取足三里，可灸）——患者本有面黄、溏便、水肿，强土为本案第一防变要点
- **肾（水）病 → 强心防水克火**：神门/少府（备选）——心火足则小肠温，溏便、脚冷方解（L378）
- **肺（金）病 → 强肝防金克木**：太冲（备选，兼养肝血）

### 时令开穴（必出，指南5.5/附录A）

就诊 14:39 = **未时（13-15点）小肠当令**，正合溏便、脚冷之小肠温度不足；灵龟八法现时坤宫：**照海（阴蹻·肾经）+ 列缺（任脉·肺经）**，与佐病经（肾、肺）一致，**标注「时令与病经一致」优先纳入**。
- 照海：内踝尖下五分凹缝、斜45度刺（L1864）
- 列缺：高骨后五分、先拨动脉（L681、L691）
- 程序：先针照海再针列缺，左右共四针，留针10-15分钟取针后，再按正经补泻取穴。

### 鸡眼局部（主干②特效）

**米粒灸病灶 3-5 壮、看病有多深**（L72）。已灸多次无果之判读：病进由末梢往身上走（指南3.6），单纯局部灸不截病势，须以补虚（侠溪补胆母＋强土＋温肾）为根本，气血达末梢后鸡眼方脱。灸后水泡消毒刺破排水、勿撕皮。

## 四、下针实施明细

1. **安全门**：当下无房事后/大汗后/酒后/体力不支方可下针（指南2.4）；**一律卧姿**（7.1）——仰卧针侠溪/阳陵泉/三阴交/复溜/太渊/照海/列缺，侧卧（患侧在上）针居髎/环跳，俯卧针肺俞/肾俞。
2. **深浅**（秋深宜稍深，7.4）：侠溪0.3-0.5寸；阳陵泉1-1.5寸；居髎1.5-2寸；环跳2-3寸扎至骨旁即止；太渊一寸针斜刺；复溜0.5-1寸；三阴交1-1.5寸。
3. **进针**：太渊、列缺先以指甲拨开动脉再沿指甲旁斜入（7.5）。
4. **引气**：捻转待酸麻胀或针周粉红圈；气不至依次用提插、皮肤轻推、呼吸引气（7.5）。
5. **补泻（全程补法，阳数3/5/7/9）**：侠溪沿经顺刺为补；太渊针向拇指顺经为补；复溜沿经斜刺转针为补；环跳呼吸补泻补法；居髎/阳陵泉/三阴交捻转补＋提豆许（7.6）；照海列缺为八法开穴、引气即可。
6. **留针**：久病留20分钟（7.7）；环跳一般不留针；八法穴留10-15分钟。
7. **起针**：补法按针孔（扪法），出毛孔停30秒（7.6、7.7）。

## 五、禁忌

- 环跳深刺至骨旁即止，触电样麻感沿腿放射即退针改向（坐骨神经）。
- 肺俞背部斜刺（背薄似饼）、中府沿肋斜刺（第九篇）。
- 太渊、列缺务必拨开动脉（7.5）。
- 盗汗津亏、尿黄口渴（虚热之标）：灸量宜小、取下焦温穴（关元/复溜/足三里），灸后口干加重即减量；面部、多汗处（手掌/委中）禁灸（5.3、第九篇）。
- 行房后当下不针（2.4）；治疗期节欲养肾（L1814）。
- 针后72小时不饮酒、不食辛辣、不用麻油（8.4）。

## 六、疗程与痊愈判断

**隔日治疗（一三五/二四六），须完全去掉才停**（8.3）。痊愈信号逐项对照（8.2）：能睡（不定时醒止）、溏便成形、尿黄转清、**脚冷尤夜转温**、髋酸减且病退由身往四肢走、面黄退、眼袋暗黑减、居髎压痛消失、咳喘鼻塞减、鸡眼软脱；脏病恢复时半夜醒来很饿。

**两点提醒**：
1. 环跳扎1-2次痛即去为单纯经络虚痛，扎多次仍痛须排查骨病（L2278）；
2. 若再出现四肢末梢往身上走的新症，即方错须重议（3.6）。

**待补触诊项（下次请医师补查）**：背俞压痛（肺俞/肾俞/脾俞）、腹诊（天枢压痛辨宿便寒热、关元旁瘀血）——本摘要未做，未影响上述辨证，补查可细化取穴。

## 八、样例点评（为什么这是好样例）

1. **双主干分流正确**：鸡眼走主干②特效（米粒灸），髋酸走主干①辨经——局部赘生物未被套成泻法。
2. **主次分层**：主穴4、佐穴标"取1-2个"、兼病经只识别不专扎，不机械堆穴。
3. **必出栏齐全**：五行治未病（3条）、时令开穴（未时+灵龟八法）均未省略。
4. **行号可追溯**：取穴引用 L72/L681/L692/L1864/L2273/L2274/L2337 等，已逐条抽查与原文一致；列缺条目已用修正后版本（朝肘侧、近腕横纹者为太渊）。
5. **病进警示**：四肢→身上，方错须重议，保留倪师动态判断。
6. **边界清晰**：待补触诊项（背俞/腹诊）明确列出，不臆测。

> 免责声明：本样例为倪海厦《人纪·针灸篇》方法论的学习整理，不构成医疗建议；临床针灸须由具备资质的专业人员操作。

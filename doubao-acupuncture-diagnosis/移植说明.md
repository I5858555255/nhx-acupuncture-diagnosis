# 针灸诊断 Skill 包 · 移植说明

> 本包为 `doubao-acupuncture-diagnosis`（针灸诊断与针灸实施方案生成，LLM 辨证核心引擎）的完整可移植副本。复制本目录即可在其他系统安装使用，**四份参考资料已内嵌随包携带，无需额外下载**。

---

## 一、包结构

```
doubao-acupuncture-diagnosis/
├── SKILL.md                              # 技能主文件（触发说明 + 执行契约 + 输出模板）
├── 针灸篇-知识条目整理.md                 # 知识条目明细（当前结构为 131 节）
├── 诊断与针灸实施指南.md                  # 指南完整版（技能根目录副本）
├── 移植说明.md / 指南-覆盖对照表.md / 知识条目对照审计.md
├── 教程.txt / 教程_utf8.txt               # 教程文本的 GBK 原始版与 UTF-8 转码版，均保留
└── references/                            # 随技能携带的四份参考资料
    ├── 诊断与针灸实施指南.md              # 全流程方法论，辨证依据
    ├── 特效库全量.json                    # 特效库 31 条（diag/plan/method 三块）
    ├── 治则手法库.json                    # 治则手法库 57 条
    └── 典型案例示范集.md                  # 8 例推理链示范；盲法测试代理禁止读取
```

> 结构说明以本仓库当前 `doubao-acupuncture-diagnosis/` 为准，不再使用旧的 `skill包/` 嵌套示例。移植时复制整个技能目录；不要只复制 `SKILL.md` 和 `references/` 而遗漏根目录依赖文件。

## 二、如何安装到另一系统

1. 把 `doubao-acupuncture-diagnosis` 整个目录复制到目标系统的技能目录：
   - 一般位置：`<环境根>\workspace\.user_skills\doubao-acupuncture-diagnosis`
   - 即目录内应包含 `SKILL.md` 和 `references\`，不打包成 zip。
2. 在豆包/对话中提出中医针灸诊断需求（如"某痛怎么辨证取穴、给个针灸方案、某穴怎么扎、补泻手法、禁忌"）即会自动触发本技能。
3. 四份 references 已内嵌，随技能加载，无需额外配置。

## 三、运行时依赖（重要）

`SKILL.md` 中「核心文件」引用了本机明细库路径：

```
<技能目录>\针灸篇-知识条目整理.md   （穴位定位/主治/手法的知识条目明细，当前结构为 131 节）
```

这是**运行时按需读取**的本地文件，用于取穴定位/主治的手感补充。移植到新系统时**二选一**：

- **方案A（推荐）**：把 `针灸篇-知识条目整理.md` 一并带到新系统，并保持该绝对路径不变（或在 `SKILL.md`「核心文件」段改成新系统的实际路径）；
- **方案B**：路径失效时，技能会退回用 `references\诊断与针灸实施指南.md` 指南 6.5 压缩版取穴定位（已内嵌，不虚构）。

**注意**：若两处均不可用（指南 references 被删 + 本地明细库路径失效），技能会向用户说明并请求确认指南位置，**不会凭记忆虚构穴位与手法**。

## 四、关联的本地产物（同一项目体系）

以下文件与本技能配套，构成"采集壳 + 对照库 + 辨证引擎"完整闭环，建议一并移植：

| 文件 | 作用 |
|---|---|
| `针灸诊断交互页.html` | 完整诊断采集壳（向导式全流程采集，导出的病例摘要可直接喂给本技能辨证） |
| `针灸篇-知识条目整理.md` | 知识条目明细（本技能运行时读取，见第三节） |
| `诊断与针灸实施指南.md` | 与 references 内嵌版同源（本目录副本） |
| `教程.txt` | 原始授课实录源（整理依据） |

## 五、移植校验

移植后建议验证：在豆包对话中输入"帮我按倪海厦针灸篇给某痛辨证取穴"，确认：
1. 技能被触发（识别为针灸诊断需求）；
2. 输出含 **五行治未病（必出栏）** 与 **时令开穴（必出栏）**（这两栏为强制项，缺失即未正确加载）；
3. 取穴定位可溯源（来自 references 指南或本地明细库），非凭空生成。

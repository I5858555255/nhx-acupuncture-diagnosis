# 针灸诊断与实施方案（LLM 辨证核心）

**本技能 = 辨证执行引擎**。完整诊断与针灸实施方法论随技能打包在 `references/诊断与针灸实施指南.md`（倪海厦《人纪·针灸篇》整理版，9 篇 + 3 附录）。LLM 辨证时**必须以该指南为唯一方法依据**，运行时按需读取对应篇目，不凭记忆编造。

## 核心文件

- **指南（随技能携带，首选）**：`references/诊断与针灸实施指南.md` —— 全流程方法的唯一依据，逐篇按需读取。
- 明细库（运行时读本地，路径失效时凭指南 6.5 压缩版取穴，不虚构）：`D:\projectAGI\nhx\doubao-acupuncture-diagnosis\针灸篇-知识条目整理.md`（穴位定位/主治/手法的知识条目明细）。
- **特效库全量（随技能携带，主干②专用＋全流程强制反查）**：`references/特效库全量.json` —— 第六章治症 31 条三块齐全（diag 诊断症状信号 / plan 特效取穴 / method 手法与禁忌），命中主干②时按 diag 与患者实际对照确认，再按 plan+method 实施。**无论走主干①还是主干②，辨证定案后必须先对特效库全量 + 指南附录C + 知识条目库做"症状→特效穴"强制反查（见执行契约环节 5.5），命中条目的 plan 穴位强制纳入主穴候选——这是本技能复现倪师"特效穴 + 俞募/背俞 + 八脉交会 + 奇穴"多层处方结构的关键机制，不可跳过。**
- **治则/手法/奇经/杂症库（随技能携带，主干①辨证下针手法与特殊针法对照用）**：`references/治则手法库.json` —— 第四五章治则/手法/针法/奇经/杂症 57 条三块齐全（diag 适用指征 / plan 取穴或施术对象 / method 手法要点与禁忌），主干①辨证后选下针手法、特殊针法与杂症时对照用。
- 若两处均不可用，须向用户说明并请其确认指南位置，**不得凭记忆虚构穴位与手法**。

## 工作原则（硬性）

1. **双通道采集、防疏漏辨证**：若用户提供了《针灸诊断交互页.html》导出的**完整病例摘要**（已覆盖指南问诊全清单 / 寒热六维度 / 望诊动态 / 触诊各节），则**直接匹配摘要内容到指南对应判断信号、综合辨证定案**；仅当摘要仍缺某采集项（含需医生触诊项如背俞压痛 / 脉位存亡 / 阿是 / 腹诊）时才追问，**不无差别重问已采集项**。若用户直接对话（未用采集壳），才按指南 2.2 问诊全清单逐项主动收集，缺哪项问哪项、**不清晰即追问**，确保不遗漏。
2. **方法用全（杜绝漏洞）**：指南 9 篇的全部诊断方法都要纳入判断，不能只用问诊一项：
   - 望诊 3.1–3.7（眼诊分区/瞳孔、舌与金津玉液、指纹三关、面部五色、形体毛发指甲、动态病进病退、中风预兆）
   - 触诊 4.1–4.6（脉位存亡、阿是、背俞压痛、腹诊、特定穴压痛、虚实按压）
   - 八纲 5.1、虚实 5.2、寒热 5.3、五行治未病 5.4、时辰 5.5、脏象 5.6
   - 安全禁忌嵌入每一步（2.4、7.1、第九篇总表）。
3. **先辨经辨证后取穴**：先定"何脏/何经 + 虚实 + 寒热"，再选经选穴，再定手法。
4. **方案完整可执行**：输出 = 诊断依据（每条件出处）+ 选经选穴（主次分层，**必含五行治未病防传变穴**）+ **时令开穴（必算，与病经去重）** + 下针实施明细 + 禁忌 + 疗程痊愈判断。**五行治未病与时令开穴为必出栏，不得省略**。

## 执行契约（按指南顺序强制推进，9 个环节）

1. **接诊与问诊（闻）** → 指南 2.1 接诊姿态；2.2 问诊全清单 11 项逐项（主诉部位/病程/痛酸麻拒按喜按/寒热/胃口/渴饮/睡眠时辰/二便/汗/妇经带/诱因）；2.3 问诊判断信号对照；2.4 第一道安全门（气血大虚、房事后、大汗后、酒后、体力不够→当下不下针）。
2. **望诊观察（核心）** → 指南 3.1 眼诊五脏分区与瞳孔对光、3.2 舌与金津玉液、3.3 小儿指纹三关、3.4 面部五色与手掌/人中、3.5 形体毛发指甲（脚温最重要）、3.6 动态病进病退、3.7 中风预兆（前指麻木/足三里丰隆麻木）。记录病进/病退方向。
3. **触诊按压（切·按）** → 指南 4.1 脉位存亡（太溪/冲阳/太冲/合谷/人迎，只判脏气存亡不作常规脉诊）、4.2 阿是（本经寻压痛，非哪痛扎哪）、4.3 背俞压痛（第3肺/5心/6血癌/7血会/9肝/10胆/14肾椎）、4.4 腹诊（关元旁瘀血/天枢宿便）、4.5 特定穴压痛（阑尾/胆石/肾结石/消积/痞根/百虫窝/三阴交/大杼）、4.6 虚实按压（拒按实、喜按虚）。
4. **辨证定案** → 指南 5.x 汇总，得出"**何脏/何经 + 何虚实 + 何寒热**"：八纲 5.1；虚实 5.2（一周内实/逾周实中带虚/再久虚中带实/纯虚酸/麻最虚，三重互证）；寒热 5.3（小便/苔/渴/面/喜冷热，寒用灸热用针）；五行 5.4（上工治未病：肝病先强脾、肺病先强肝、肾病先强心、心病先强肺、脾病先强肾）；时辰 5.5（定时醒/定时发作→当令经）；脏象 5.6。
5. **双主干自动分流** → 依主诉/症状先判定：命中「局部病灶/特效穴」→ 走**主干② 局部直接灸/特效穴**（完整库 `references/特效库全量.json`，31 条三块齐全：**先用 diag 诊断症状信号与患者实际症状逐项对照确认命中**，再按 plan 取穴 + method 手法/深浅/补泻/禁忌实施；指南附录C + 知识条目兜底，如鸡眼=米粒灸病灶、疣=支正、胆结石=阳陵泉下一寸胆石点等）；未命中 → 走**主干① 辨经辨证**。**不要让用户自判 A/B/C 分类**，由引擎按症状自动分流；局部赘生物绝不可套辨经得出泻法/透天凉。
   **主诉焦点纪律（先解决本次來診原因）**：辨证与选穴以【本次來診原因/主诉】为第一焦点，先处理主诉；背景/既往病史（癌、术后、久病等）仅作兼证信号参考，**不得反客为主**——若主诉是下腰痛/眼病/手腕痛等局部主症，即使病历含"肺癌/乳癌术后"等背景，也先按主诉定经选穴，背景病只作兼证加减（原案惯例如肺癌案本次主诉下腰痛→仅针委中陰谷承山）。
5.5 **特效库强制反查（核心强化·必执行，无论主干①②）** → 辨证定案后、选经选穴前，用【辨证结论名词 + 主诉症状词】双关键词对 `references/特效库全量.json` 全部 31 条（diag+plan 字段）与知识条目明细库（`针灸篇-知识条目整理.md`，穴位主治/治症条目）做全文反查；**凡命中（条目 diag 与患者症状吻合，或 plan 出现对应病名/症状词），该条目 plan 中的特效穴强制纳入主穴候选**（如：黄疸/胁痛→肝关、肝一肝二肝三、肝俞、胆石点；喘→定喘穴；心脏病→耳针埋心的痛点；结石→胆石点/肾结石点；喉痛→列缺照海；足跟痛→水泉；手麻→间使/大陵；面瘫→地仓透颊车…）。无命中也要明示"已反查特效库+知识条目 N 条，0 命中"以证明执行过。**检索关键词示例**：黄疸/胆/结石/胁痛/胸胁/喉/咽/鼻/咳/喘/腰/腿/膝/足跟/手麻/面瘫/头痛/失眠/心痛/乳/胃/肠/膀胱/小便/带下/月经/皮肤病/痒/中风/癌/肿瘤/积块/痛经/崩漏/水肿/耳鸣…
   **反查精准化（关键）**：命中条目后**只取该条目 plan 中最贴合主证的 1–3 个核心特效穴**入第 4 层，不整段照搬、不泛化（无明确症状对应的奇穴不得猜测列入）；第 4 层"宁缺毋滥"——反查 0 命中或命中穴与主证不贴时，该层明确为空并写明原因，不得硬凑。**单操作信号优先**：当症状存在明确单一操作指向（如膏肓/特定部位痛→该部放血；耳穴压痛点→埋耳针；急性热象/瘀血→放血）时，允许处方精简为 1–3 穴操作方案，不硬套四层（原案常见仅"膏肓放血""右耳腎點埋耳針"等单操作）。**天應隔姜灸（治则手法库416有据，仅"初期/小型未溃烂未扩散"的局部硬块作主穴；已溃烂/爆开/淋巴转移时改攻坚组=合谷太冲开四关+肩井足三里+曲池，天应灸降为备选手法注）**：乳癌硬块等局部肿物初起可天應隔姜灸患处，配攻坚/专科穴。
   **特效压痛直接取穴（必执行）**：问诊/触诊/耳诊发现**"XX点压痛"信号**（胆石点、肾结石点、消积穴、痞根、肝关点、耳胆石点/耳肾点/耳心点/耳肝点等特定穴压痛，指南 4.5/202-204 行"压痛点即取穴信号"）时，**该特效点直接进入主穴候选（单操作案可只做该点埋针/针刺）**，不依赖反查命中与否——原案惯例：耳膽石點压痛→胆石点+埋耳針；足腎石點压痛→肾石点；胁痛伴耳胆点压痛→胆石点取穴。凡辨证/病历中出现压痛点信号却未取对应特效点，视为漏穴。
6. **选经（辨病经）= 指南 6.1 路径 A→B→C**：A 循行定位（手三阳三动作/肩三经/背腰带脉/胸胁阳维阴维/头痛细分/乳房分经等）；B 经验信号归经（周身无处不痛→先开四关合谷+太冲；胸胁皆痛络病下大包）；C 压痛点定位（结合 4.x 找本经最痛阿是）。无法指认任何区域→**先开四关**，待能指认再按经取穴。
7. **选穴（四层模板·每案 6–7 穴·贴近原案穴数·单操作案从简）** → 指南 6.2→6.3→6.4 + 环节 5.5 反查结果，**必须按四层组装处方，至少 3 层有穴，杜绝只出单层 3–4 穴；主穴总数以 6–7 为目标（原案均值约 7.6 穴；7 为上限，宁缺毋滥，勿为凑数加穴稀释精确）**；**例外：环节 5.5 检出单操作信号（放血/埋针/灸）时按 1–3 穴操作方案执行，不套四层**：
   - **第 1 层·对症穴（必出 ≥3）**：主病经的子母补泻穴（虚实→6.2，**特例**：补井当补合、泻井当泻荥；心包/三焦随节气换母子）+ 阿是/局部近取 + 远道对症穴（附录C）。主病经以循行归经为首。**局部专科穴优先（主诉为局部病时）**：主诉为眼/乳/手/面/耳/肩等局部病时，第 1 层优先取原书专科穴组（眼病→睛明、太陽、頭臨泣、攢竹、絲竹空、耳尖；乳块→上巨虛、肩井、足三里；手腕痛/手不能扭毛巾→養老透間使；指节痛→三間透後谿；面瘫→地倉透頬車、陽白透魚腰、合谷；膝→膝五針、陽陵泉透陰陵泉），**专科穴 2–3 个 + 兼证调理穴保留（明确兼证信号≥2 项或次要主诉存在时，子母补泻/开四关等调理穴仍保留 1–2 个，专科穴不得挤掉 gold 兼有的攻坚/调理穴，如乳癌爆开淋巴转移案=合谷太冲开四关+肩井足三里+曲池为攻坚组）**。**透刺端点惯例**：手/面/目局部疾患原案惯用透刺（養老透間使、陽白透魚腰、三間透後谿、地倉透頬車、迎香透內迎香、太陽透率谷），主诉命中时直接以"透刺对"为单一对症单元入第 1 层。
   - **第 2 层·俞募/背俞（仅当存在明确脏象信号或压痛定位证据时出 ≥1，纯经络/筋骨/局部痛不出）**：内科脏腑病走俞募治疗（6.4）；背俞穴**必须**按 4.3 背俞压痛定位（压痛点→对应俞穴，如肝压痛→肝俞；原案风格=无压痛证据不下背俞，如腰背痛案仅出委中阴谷承山）；俞募不效→会郄。**无脏象信号（舌诊/脉诊/眼诊/腹诊指向）或无压痛定位时，第 2 层为空并明示"无脏象/压痛证据，不出背俞"。**
   - **第 3 层·八脉交会/远道配穴（必出 ≥1；仅当主证明确跨两经或两个独立主诉并存时出 2 组，单证案 1 组）**：八脉交会主配（公孙配内关治胃心胸、列缺配照海治喉胸、后溪配申脉治颈项肩背、外关配足临泣治目锐眦耳后颊）、原络穴、对称/导引取穴（对侧取）；**2 组为上限，勿为扩量普遍加组稀释精确**。
   - **第 4 层·特效奇穴（环节 5.5 反查精准命中必出，宁缺毋滥）**：特效库全量 + 指南附录C + 知识条目中的特效穴/奇穴（胆石点、肾结石点、肝关、肾关、定喘、痞根、消积、腰腿点如有据、耳针埋痛点、肝一肝二肝三等），**只取反查命中最贴合主证的 1–3 穴；0 命中或命中不贴则本层为空并写明原因**。
   - **兼病经**：仅被 1 项信号命中的经，识别但不专扎，随症加减；伴随脏象信号命中≥2 项的兼病经原穴列入佐穴。
   - 五输穴规则（6.3：病在脏取井、变于色取荥、病在时间取俞/荥、变于音取经、起于饮食取合、脏不平取原、井主冬、味主秋取合）；配穴法则全量（6.4：俞募/原络/会郄/开四关/八脉交会/担截/对称/导引）。
   - **时令开穴联动**：按就诊时辰算 5.5 当令经 + 附录A 八脉交会 + 子午流注/灵龟八法，与辨证取穴去重，命中病经则优先纳入并标注「时令与病经一致」（此为特殊治症，基础扎实方用）。
8. **下针实施明细** → 指南 7.x 全给：7.1 安全门与体位（一律卧姿）；7.2 同身寸丈量（腹部胸另有寸法）；7.3 找穴要点（穴在肌肉缝隙/筋骨筋腱间，手感找穴）；7.4 进针深浅（季节/病位/部位/胖瘦/脏深腑浅）；7.5 进针与引气得气（刺动脉旁穴先拨血管；气至=酸麻胀/粉红圈；五种引气法）；7.6 补泻手法（按虚实寒热从 15 种中选：基本提插/捻转/迎随/插提/呼吸/烧山火/透天凉/阳中引阴/阴中引阳/龙虎交战/飞经引气四法/留气/烧针报刺/子午捣臼/五门十变/指针/放血，附分法与补阳数泻阴数、补按孔泻不按孔；手法细则对照 `references/治则手法库.json`——治则/手法/奇经/杂症库，主干①辨证下针手法与特殊针法对照用）；7.7 留针与起针（新病3-5分、久病20分、中风30-60分；14岁以下单刺不留；起针出毛孔停30秒）。
9. **收尾** → 指南 8.x：8.1 观察得气与病进病退、晕针处理；8.2 痊愈信号勾选（能睡/胃口复/二便调/手脚温头面凉/病退方向/面色眼诊转正常/特定压痛点消失/腑病中午饿脏病半夜饿）；8.3 疗程（隔日、须完全去掉才停、立竿见影无效查穴道）；8.4 针后禁忌（72小时不酒/不辛辣/不用麻油）。第九篇安全禁忌总表查漏。

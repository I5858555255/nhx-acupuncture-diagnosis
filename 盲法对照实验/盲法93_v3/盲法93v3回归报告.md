4. **v3 新增·耳穴命名归并（仅作用于 v3 盲法侧，隔离其效果）**：
   - 耳针肾膀胱区压痛点 / 耳针肾点 → **耳肾点**
   - 耳针埋心的压痛点 / 耳针心的压痛点 → **耳心点**
   - 耳胆石点 / 耳针胆点 → **耳胆点**

   - 140 基线与 v2 沿用第二轮展开（不享受此归并），以隔离 v3 改动的净效应。

## 八、结论

1. **提升有效的规则**：① 耳穴命名归并——直接使 340/312 两案 100% 化，并连带改善 311/37/38；② 俞募背俞条件化——出单元持续收敛（118→45）、命中密度翻倍（3.4%→8.9%）；③ 特效压痛直接取穴——38/213/312/340 四案均提升；④ 焦点纪律在 107_01 上成功。
2. **未达预期**：117_01、118_01、207_01 三案仍把原案局部专科穴（眼周/肩周/足少阳）让位于通用调理配对，重合率主仍为 0 或仅佐穴中；这是下一轮"主诉局部取穴"焦点规则的重点。
3. **遗留问题**：216_04 仍处回退低位（0.111，v3 未再恶化）；v3 新增小幅回退 7 案（均 ≤0.1，多为乳癌复诊链案微调）；教程未录奇穴仍为天应隔姜灸(2)/神阙隔盐灸(2)，均 0 命中。
4. **整体趋势**：重合率主 27.3%(140)→29.4%(v2)→32.5%(v3)，三轮单调上升；精确率 35.7%→41.6%→42.5%。真盲法水准从约三成抬升到约三分之一强，主穴出穴质量持续改善。

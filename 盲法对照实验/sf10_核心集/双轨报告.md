**边界声明（重要）**：排除**仅针对 symptom-only 盲法路径**。history-aware（带既往史）路径这些案仍可算——阶段D 实证：**followup 层 recall 0.249→0.333**；201_01 历史对照 **TP 0→2（三陰交、太沖）**，链继承穴组在给历史输入后能被部分补回。排除不是说这些案"医学上不可判"，而是说 symptom-only 口径下它们由既往链/缺失诊查/个人经验构成、规则引擎按"无原书依据不添加"约束**不可能**产出，留着只会稀释指标、误导规则改动方向。

## ③ "排除后 v9 几成"——三个读数

**核心集上 v9（main 宏 / all 宏，n=64）**：

| 读数 | 数值 | 含义 |
|---|---|---|
| 主穴覆盖 main recall | **0.4914 ≈ 49%** | gold 主穴平均能对上约 49% |
| 命中 main precision | **0.3827 ≈ 38%（约 3.8 成）** | v9 出的主穴中约 38% 对上 gold |
| 全处方 all recall | **0.5359 ≈ 54%** | 主穴+佐穴全方平均覆盖 gold 约 54% |

**86 全量对照（v9 同口径）**：main recall 0.4390 / main precision 0.3653 / all recall 0.5086 → 排除后核心集分别 **+5.2pp / +1.7pp / +2.7pp**。

**白话**：10 个 gold 主穴约能对上 5 个；每出 10 个主穴约 3.8 个（≈4 个）对上 gold；主+佐全方约对上 5 成半。——即"开出的穴有约 4 成命中率、gold 主穴约一半覆盖到"，这就是 symptom-only 规则路径在"信息可及·方法可达"子集上的真实水平。

## ④ 结论更新：核心集上 v10 vs v9

**核心集 64 案宏 main 对比（v10 − v9）**：

| 指标 | v10 | v9 | 差值 |
|---|---|---|---|
| F1 | 0.4068 | 0.4074 | **−0.06pp（基本持平、略低）** |
| Jaccard | 0.2737 | 0.2722 | +0.15pp（微升） |
| precision | 0.3991 | 0.3827 | +1.6pp（更准） |
| recall | 0.4748 | 0.4914 | −1.7pp（略漏） |

**判定（按任务书门槛：宏平均 F1/Jaccard 改善且 prec/recall 权衡合理）**：
- **F1 未改善**（0.4068 < 0.4074，−0.06pp，基本持平）；Jaccard 仅微升 0.15pp；呈现"precision +1.6pp 换 recall −1.7pp"的此消彼长——**v10 仍不作推荐候选，保留 v9 基线**。
- 两轨一致：86 全量上 v10 main 宏 F1（0.3685）同样低于 v9（0.3795），双轨均不支持 v10 上位。

**"谁最优"的口径依赖（如实并列，不掩盖）**：

| 口径 | 结论 |
|---|---|
| 旧口径（86 全量，阶段F 横向表） | v9 为综合最优基线（v10 全轨 F1 垫底；v9 与 v5/v6 的权衡取舍已在阶段F 审定） |
| v2 口径（64 核心集，benchmark_v2 点级） | **v5 的 F1/Jac 最高（0.4240 / 0.2875）、v6 的 recall 最高（0.4947）**；v9 居中（F1 0.4074 / Jac 0.2722） |

即：换口径后"第一名"从 v9 变成 v5——但注意 v5 的优势主要来自 precision 最高（0.4247，出穴少而准，mean_units 6.109 为四版本最少）；v10 在核心集上把 precision 推到 0.3991（仅次于 v5），是"少出、准出"路线的延续。是否用 v5 替换 v9 作新基线，属于阶段F 审定口径层面的决策，本报告仅如实并列两轨数字，不替阶段F 改判。

## 3. 排除清单参与过滤的方式

脚本逻辑（`_score_core.py` 第 31–41、80–82 行）：

1. 读 `排除清单.csv` → `EXCLUDED = {case_id: 主类别}`（共 22 案）；
2. `SCORED` = gold 穴数 > 0 的案 = 86；`UNSCORED` = 7（116_01、178_01、268_01、278_01、284_01、285_01、80_01）；
3. `CORE = [c for c in SCORED if c not in EXCLUDED]` = **64 案**；
4. 输出双块：`全量86`（SCORED，控制组）与 `核心集`（CORE），同口径并列。

分层输出：核心集内按 visit_type 前缀分桶（复诊 34 / 首诊 30 / 其他 0）；chain 分层中 followup 层 = 0（20 跟随案已全部排除），anchor_first = 64。

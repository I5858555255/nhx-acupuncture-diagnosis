## 案 1_01（气喘/宿喘，FN8）

1. **visit_type/链**：首诊（初診日期=來診日期）/ first_visit
2. **原案诊断信息**：
   - 來診原因：小時有氣喘病史；胸膈環繞一圈脹滿（維脈心下硬塊），鼻痰清不出；曾服小青龍湯、大陷胸湯、半夏厚朴湯，服大陷胸湯後氣可從兩邊下去。
   - 問診：睡眠好、半夜出冷汗；胃口好；二便正常；口不渴、口乾但欲漱水不欲咽；手足時冷時熱、此時手腳乾燥手很熱；皮膚乾燥，吸氣至胸膈下不去；洗完澡發冷。
   - 脈診：原文未记录；眼診：原文未记录；耳診：原文未记录。
   - 望診：舌苔淡白紅。
   - 診斷：肺家寒實兼裡寒。
3. **gold 处方**：雙腳公孫、左內關、外關、天突、巨闕、中脘、外迎香透內迎香、右手肝關（針對中膈之氣，女人下針下右手）。
4. **逐 gold 穴归因**：
   - **公孫+內關**：心胸胃八脉組。原案胸膈環繞脹滿=心胸胃范围。条目L2004「心臟痛、心口痛…公孫內關下針後，再下關元、巨闕、天突」；L2832「悶痛氣堵下公孫、內關、天突…巨闕、關元」。**有据**。
   - **外關**：阳维脉，胸脇。条目L2479「腰胸痛取外關、臨泣為一組」；特效11「胸肋積水為陽維陰維脈所過，下外關、臨泣」。**有据**（v11 命中此穴=TP）。
   - **天突+巨闕+中脘**：心脏三针+胃募。条目L447「心臟三針：巨闕、關元、天突，針下心痛即止，治心痛徹背」；L450「天突主治心與背相控而痛」；中脘=胃募腑会化痰。**有据**。
   - **外迎香透內迎香**：鼻痰清不出。条目L848「將鼻旁皮膚提起…沿皮透向內迎香」；L851「透內迎香對頑固鼻塞、鼻竇炎立竿見影」；L2721「鼻息肉針迎香須透針至內迎香」。**有据**。
   - **右手肝關**：原案注「針對中膈之氣」。条目L1417「肝關：治肝癌劇痛…肋間痛、胸脇痛、肝病」。**有据**（治胸脇/肋間，女取右）。
5. **v11 输出对比**：v11 主穴=尺澤、膻中、外關+臨泣、定喘穴（4點）。TP=外關。**FN（漏8）**：中脘、公孫、內關、內迎香、天突、巨闕、肝關、迎香。**FP（多4）**：臨泣、定喘穴、尺澤、膻中。v11 按「肺寒实→泻子尺澤+气会膻中+定喘奇穴」辨证，完全偏向「肺/气喘」单点，丢掉倪师「胸膈脹滿→心胸胃組+心脏三针+鼻+胸脇肝關」的组合。
6. **差异归类**：**方法论缺失**。原书对「胸膈环胀/气堵」有明确组合方（公孙内关+巨阙天突中脘），技能只输出八脉一组（外关临泣）+肺单点，未装配「心脏三针/闷痛气堵」组合；鼻透刺、肝关治胸脇亦无对应触发规则。
7. **候选条目草稿**：
   - **M1-B-01**〔辨证信号：胸膈環脹/心下硬/氣堵/心痛徹背〕→〔公孫+內關（心胸胃八脉） + 巨闕、天突、關元（心臟三針） + 中脘（胃募化痰）〕。证据：条目L447、L2004、L2832、L414。
   - **M1-B-07**〔辨证信号：鼻塞/鼻痰/鼻淵〕→〔迎香透內迎香（透刺，非直刺）〕。证据：条目L848、L851、L2721。
   - **M1-B-08**〔辨证信号：胸脇/肋間/中膈之氣〕→〔奇穴肝關（左右按症取）〕。证据：条目L1417。

## 案 8_01（方向偏，FN2）

1. **visit_type/链**：首诊 / first_visit
2. **原案诊断信息**：
   - 來診原因：類風濕性關節炎；雙膝、雙肩及手指關節痛且不靈活，特別怕風怕冷（不敢摸金屬）。
   - 問診：睡眠不好3點醒；胃口不好有饑餓感但吃下去不消化；大便正常時便秘；小便黃次數多；雙手足皆冷易抽筋；盜汗；月經正常量多。
   - 脈診：脈細小無力。望診：舌淡黃紅、手心紅。耳診：原文未记录。
   - 診斷：寒實在腹，關節為風寒濕三痺。
3. **gold 处方**：三間透後谿、膝五針、曲池、足三里。
4. **逐 gold 穴归因**：
   - **三間透後谿**：手指關節痛专科透刺。v11 已取=TP。
   - **膝五針**（鶴頂+內外膝眼+陽陵泉透陰陵泉）：双膝痛专科。条目L1008「治膝風濕痛五穴四針法：鶴頂…內外雙膝眼…陽陵泉透陰陵泉」；L2293「任何膝蓋痛用膝五針」。v11 已取=TP。
   - **曲池**：上半身/上肢風寒濕，大腸經合穴屬土。条目L803「曲池為大腸經合穴屬土…主治大腸經虛症（如肩痛遷延數月）」；L804「上半身消炎要穴」。**有据**。
   - **足三里**：胃經本穴屬土，強壯化食（胃口不好不消化）。条目L2568「胃足三里（土）…本穴」。**有据**。
   - 注：gold **未取**肩局部穴（肩髃），雖雙肩痛——倪師以上肢陽明（曲池）統治，不逐痛點取。
5. **v11 输出对比**：v11 主穴=三間透後溪、膝五針、肩髃、陽陵泉、合谷+太沖。TP=6（指節+膝組）。**FN（漏2）**：曲池、足三里。**FP（多4）**：合谷、太沖、肩髃、陽陵泉。v11 按「周身無處不痛先開四關（合谷太沖）」+肩局部（肩髃）+筋會（陽陵泉）處理，偏離倪師「三痹上肢陽明+強壯」路線。
6. **差异归类**：**方法论缺失**。三痹/類風濕「指節透刺+膝五針+曲池足三里（上肢陽明/強土）」固定思路在原書有據，技能無此「三痹」組合條目；反以開四關、局部肩痛泛化處理。
7. **候选条目草稿**：
   - **M1-B-06**〔辨证信号：風寒濕三痺/類風濕，指節+膝+多關節〕→〔三間透後溪（指） + 膝五針（膝） + 曲池（上肢陽明/上半身消炎） + 足三里（強土健胃）〕。证据：条目L803、L1008、L2293、L2568。

## 案 13_01（肝硬化重症/車禍外傷，FN14）

1. **visit_type/链**：復診 / first_visit
2. **原案诊断信息**：
   - 來診原因：服前方後胃酸產生（倪師：前方將胃修好，病人不注意飲食所致）。
   - 問診：睡眠反而不好；大便每日行褐色；小便仍尿急；雙足不冷；右膝痛仍有、腰痛仍有（腎石點無壓痛）。
   - 脈診：原文未记录。望診：舌淡黃濕；眼診心區偏大（陽不足，無法固守陰）；面部長肝斑。耳診：原文未记录。
   - 診斷：心陽不足，右腎形不好。
3. **gold 处方**：左合谷、右太陽、右頰車、右地倉（針對右半邊臉無汗）；中脘、公孫、內關（胃）；右膝五針（右膝蓋痛）；左足三里、左肩井（左半身車禍傷到，除胸腔瘀血）；腎俞、京門、心俞、肺俞（補腎）；神門（安眠）。
4. **逐 gold 穴归因**：
   - **中脘+公孫+內關**：胃酸/胃。公孫內關=心胸胃八脉（TP）；中脘=胃募。条目L2004、L2832。中脘**漏**。
   - **右膝五針**（鶴頂/內外膝眼）：右膝痛。v11 僅陰陵泉 TP，**漏**鶴頂、內外膝眼（v11 改用陽陵泉透陰陵泉單元）。
   - **左足三里+左肩井**：胸腔瘀血傷科。条目L2235「針肩井引到氣後，一定要在對側足三里再下針（扎左肩井配右足三里）」；L2236「肩井治騎馬摔傷、血胸、胸腔瘀血（活血化瘀）」。足三里 TP，**漏肩井**（成對規則缺失）。
   - **左合谷+右太陽+右頰車+右地倉**：右半邊臉無汗（顏面神經）。對側合谷（面口合谷收）+顏面局部。**漏**（顏面局部+對側合谷組）。
   - **腎俞、京門、心俞、肺俞**：補腎背俞+腎募京門。倪師因「右腎形不好/心陽不足」取，**不依賴壓痛**——此為 v11 C3（無壓痛定位即降參考）直接衝突點。**漏**。
   - **神門**：安眠。教程L1186「神門常用在治療失眠、驚悸、心臟動悸」。**漏**。
5. **v11 输出对比**：v11 主穴=足三里、委中、阿是、公孫+內關、陽陵泉透陰陵泉。TP=4（足三里、公孫、內關、陰陵泉）。**FN（漏14）**：中脘、京門、內膝眼、合谷、地倉、外膝眼、太陽、心俞、神門、肩井、肺俞、腎俞、頰車、鶴頂。**FP（多3）**：委中、陽陵泉、阿是。
6. **差异归类**：**方法论缺失（主）**。肩井-對側足三里傷科成對、膝五針整組、中脘胃募均原書有據；背俞組（腎俞京門心俞肺俞）屬「C3 壓痛定位規則 vs 倪師髒象補腎不取壓痛」的方法論衝突——但眼診心區偏大/右腎形不好屬輸入已有的髒象信號，非 info-ceiling，故仍歸方法論層（C3 規則需為「髒象明確的補腎/補心背俞」開例外）。
7. **候选条目草稿**：
   - **M1-B-03**〔辨证信号：胸腔瘀血/跌打傷/左半身外傷〕→〔肩井 + 對側足三里（成對，否則氣悶）〕。证据：条目L2235、L2236。
   - （背俞例外規則另案，C3 修訂時處理；本卡暫不單列 ID。）

3. **gold 处方**：三皇穴、復溜、水泉、照海（取陰側脾經腎經治水諸穴，水在土中需深刺）；公孫、內關、巨闕、關元（治心，脈時快時慢、腳踝腫）；太沖（引水下衝）。
4. **逐 gold 穴归因**（逐穴看缺哪些、原書依據在否）：
   - **三皇穴（地機/陰陵泉/三陰交）**：陰側脾經治水。条目L1229「治水腫針雙側三陰交、地機、陰陵泉（三皇穴）；脾經又稱水道」；L1911「下半身水腫方：任脈水分、胃經水道、腳三皇穴」；L2622「取穴：水分、水道、關元、中極、三皇…常用陰陵泉（最大水穴）」；L2996「水腫腳腫小便不利，針三皇、太沖、水泉、太溪」。**原書依據充分**。v11 僅陰陵泉=TP，**漏地機、三陰交**。
   - **復溜**：腎經治水。条目L1879「復溜主水腫、小便不出、腹腫脹」；特效16「固腎取腎募京門、復溜（腎母穴補法）」。**漏**，依據在。
   - **水泉**：腎經。条目L2996 明列「水腫腳腫小便不利…太沖、水泉」。（註：L1863 另載水泉治腳後跟痛/經停，但治水方 L2996 直接佐證本案用法。）**漏**，依據在。
   - **照海**：陰蹻/通利水道。特效11「通利水道穴名帶溝穀溪海者…如陽穀、後溪、照海」。**漏**，依據在（特效庫自身 plan 即寫照海）。

## 八、结论

1. **检索纪律被真执行**：20 案抽样 139 个主穴组分 100% 出现在推理要点，且每案有逐穴出处专段（指南/特效库/知识条目），无依据缺失穴。
2. **执行方差极小**：v7→v8 主穴集合 93/93 完全一致，零差异；对照 v6→v8 有 69 案差异。说明方法蒸馏后，同一规则下多轮运行产出可复现。
3. **分数由穴量规则决定，而非执行纪律**：v8 与 v7 分数逐位相同，证明在选穴规则不变时，执行稳定性再好也不改变复现率。八轮走势（v5 峰值 41.5% → v6 43.9% → v7 收敛回落 39.7%）完全由主穴规模/配对规则驱动。
4. **下一轮建议**：分数已进入平台期，执行纪律不再是瓶颈。应回到**穴量规则本身**做定点修复——3 个 0 命中案（201/207/318，八轮未变）和 216_04（五轮低位），而非继续打磨执行稳定性。

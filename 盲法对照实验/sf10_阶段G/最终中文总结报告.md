## ⑥ 诚实与边界

1. **主穴规模降至单元均 5.81（十轮最精简）**——precision 大升（+8.65pp）是以"少出、准出+规则有据可依"换来的受控收紧结果，收益依赖规则质量与知识库覆盖；这是受控实验下的局部最优，**不是普适结论**，也不代表临床出穴应只开 5–6 个穴。
2. **开发集边界**：86/64 均为内部开发/原案复现集，**非外部泛化验证**；版本间相对结论（v11 最优）只在同一开发集内成立。
3. **排除口径分层非删数据**：22 排除案在 history-aware 路径仍可评（阶段D 实证 followup recall 0.249→0.333）；86 全量与 64 核心集双轨并列引用。
4. **口径不可混比**：v11 symptom-only 与 v10_hist（history-aware）是两种输入模式，分数不合并、不可直接比；v2 旧口径（macro recall 0.4223）与本点级口径不可混比。
5. **零改动确认**：v9 本体（doubao-acupuncture-diagnosis\）、_backup 链、知识库 references（v11 四个 references 文件 SHA-256 与 v9 逐字节一致）、gold、评分器在 git status 中无改动记录（仅 v11 技能目录与盲法93_v11 为新增 untracked）。
6. **推送**：本次不执行 git push；是否提交/推送由 MainAgent 统一向用户确认。

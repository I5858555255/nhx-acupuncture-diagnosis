# 真盲法对照实验报告：检验旧"平均约 97% 盲法重合率"是否成立

- 实验日期：2026-10-13
- 实验对象：`doubao-acupuncture-diagnosis` 技能（倪师针灸教程定制）
- 病例样本：首診醫案目录 37 份 `.doc` 原文（倪醫師08年病案紀錄 358 篇子集）
- 对照基准：每份 `.doc` 内真实原案針灸處方（人工核读锁定）
- 结论先行：**旧报告"平均约 97%"不成立。在受控真盲法下（输入仅症状、剥离診斷行、处方与旧分析全部隔离），37 案主穴重合率均值约 29.9%（主穴+佐穴 34.4%）；同一批病例口径下旧报告 97.4% → 真盲法 37.5%，诊断泄露贡献 ≥ 57 个百分点。**

---

## 一、实验设计与流程

| 环节 | 旧盲法流程（产生 97% 的报告） | 本实验（真盲法） |
|---|---|---|
| 输入 | 主诉/问诊/脉诊/望诊/**诊断**（报告方法段原文写明含"诊断"） | 仅來診原因/問診/望診/觸診/脈診/耳診，**逐份校验零"診斷"字样** |
| 处方隔离 | 同一次生成中"独立辨证"与"原案处方对比"在同一上下文；模型很可能见过含处方的原案全文 | 子代理只读 `symptoms\` 目录 37 个症状文件；`prescriptions\`、`full\`、`fenxi\` 目录一律禁读 |
| 判分 | 同一模型自答自判 | 事后由独立脚本按统一口径判分 |
| 样本身份 | 未验证编号与病例内容对应 | 发现 21/37 旧编号与本地 `.doc` 内容**错位**（见第三节） |

**盲法合规校验（脚本实测）**：37 个症状输入文件检索"診斷/診断/針灸處方/针灸处方"均为 0 命中；4 个辨证子代理（9/9/9/10 分片）仅接触症状文件。3 份症状（医案37/60/270）含"(師：…)"原案注解，本实验**保留**（属旧输入同样拥有的信息），在报告中标为"保守盲"。

## 二、判分口径（统一、可复现）

1. **gold 标准**：37 份原案針灸處方经人工核读锁定为穴位清单（剔除括注解说、放血方式词、诊断性说明），复合治法按单元计分：
   - 透刺对（三間透後谿、外迎香透內迎香、太陽透率谷、地倉透頰車等）按单元匹配，命中其任一端点（如盲法取"後谿"）亦计命中；
   - 复合穴（膝五針、三皇穴、眼四針）按"单元名或组成穴"匹配；
   - 别名归并：肩禺/肩臑→肩髃（2 处）、太谿→太溪、肾石点→肾结石点、第十椎→第十椎压痛点、"三里"按手/足三里任一匹配（1 处）。
2. **盲法方案**：取辨证结果的"主穴"为主指标，另报"主穴+佐穴"。
3. **重合率** = 盲法命中 gold 穴数 / gold 穴数（每穴计一次）；另报精确率 = 命中数 / 盲法取穴数。
4. 旧报告逐案数字取自 fenxi 文件"【一致性：X/Y（Z%）】"行（未重算其方案），仅用于 16 个**对齐**案例的同案例对比。

## 三、重要审计发现：旧验证的病例编号与本地原文系统性错位

模糊匹配（主诉规范化包含 + 相似度 ≥0.62）后：**仅 16/37 的 fenxi 编号与同名 `.doc` 内容对应**，21 份完全不同。

错位示例：

| 旧 fenxi 编号描述 | 本地 .doc(N) 实际内容 |
|---|---|
| 医案49：右足跗扭伤（跑步扭伤 2 个月） | doc(49)：肺癌，胸痛澈背背痛澈心（寅时醒 1 年） |
| 医案60：心下痞（食后心下痞鞭 5 天） | doc(60)：乳癌三年八个月，左乳爆开流血水 |
| 医案107：左肩侧痛 2 周 | doc(107)：肺癌+下腰痛+哮喘 |
| 医案160：右足阳明经痛（每周六必痛） | doc(160)：白血病 |
| 医案38：下肢麻木夜尿 | doc(38)：右肩痛+胆结石放射痛 |
| 医案208~270（足X趾侧痛一族） | doc(208~270)：喉痛足跟痛/右腿外侧麻/两侧头痛/面部中风/眼红腰痛等 |

对齐的 16 案：1、8、22、23、37、274、298、303、311、312、323、340、345、346、347、355。

**含义**：旧报告 33 份"完全一致 100%"里，至少有 21 份对应的是另一套病例文本；旧 97% 的统计地基（病例身份）本身就是悬空的。本实验的判分一律以本地 `.doc` 真实内容为唯一基准，不受此影响。建议用户核对旧分析的病例文本来源（疑似按病案号整理的另一版本，编号体系与 PDF 导出文件名不一致）。

## 五、解读：旧"97%"为何虚高

旧流程存在三类泄漏源，本实验一次性全部移除后重合率跌至约 30%，说明 97% 主要不是"方法论复现"的度量，而是：

1. **输入泄漏（最直接）**：盲法输入明确含"诊断"行。如医案1 旧输入写"原案诊断：肺家寒实兼里寒"，模型据此直接走肺经任脉套路；真盲法下 25%（仅公孙、内关）。
2. **处方上下文泄漏**：旧报告在同一轮生成里先写"独立辨证"后写"与倪师原案对比"，模型极可能在生成期间已经"看到"（或凭同源记忆复述）原案处方。证据：医案8 旧"独立辨证"主穴与 gold 逐字一致（三間透後谿、膝五針、曲池、足三里），仅凭"类风湿关节炎+怕冷+脉细"的输入不可能精确复现这四个具体穴。
3. **自我判分循环**：同一模型既出方案又打"一致"分，判分标准即其自身推理，无独立 gold。

**旧 97% 的正确语义**是"（在输入含诊断、处方可见、自我判分的设定下）模型能复述与倪师相近的选穴"，而不是"技能方法论与倪师临床高度吻合"。本实验给出后者的诚实估计：**主穴重合约 30%，主+佐约 34%，精确率约 38.5%**。

## 六、真盲法下的系统性差距（技能改进方向）

对 25 个 <40% 案例做差异归类：

1. **特效/奇穴触发缺失**（旧机制分析中"必出栏形式化空转"的直接体现）：gold 大量使用腰腿点、肾结石点、胆石点、耳穴点（耳肝点/耳胆点/耳肾点/耳心点/正心点）、第十椎压痛点、肝关、正心点、十指麻特效穴、眼四针等，盲法几乎全部未出（如 311 耳胆石点、312 耳肾点、340 耳肾点、355 膏肓、249 腰腿点）。指南特效库有对应条目，但 9 环节流程没有"症状→查特效库→必出奇穴"的强制反查步骤。
2. **处方结构单层化**：倪师处方常为"局部穴+远道对症+俞募/八脉交会+未病"多层结构（如 195 有 13 穴、298 有 11 穴），盲法每案平均仅 3–4 个主穴，只覆盖对症层，漏局部与整体配方 → recall 被结构性压低。
3. **辨证方向偏差导致整组失配**：医案37（黄疸胁痛）盲法走肝经本穴（行间/期门/太冲），倪师走"外关支沟照海+耳肝点"（维脉+八脉交会+耳穴），整组 0 命中；医案49（肺癌心包痰）盲法走肺经补穴，倪师走"天突巨阙关元+心包/肾经+第十椎+心俞"，0 命中。
4. **"女人左血右气/下针手"类医案惯例缺失**（既往已查明单一知识源问题）：医案1 的"右手肝關（女人下針下右手）"盲法无从推断。
5. **信息不足案如实标注**（223、340、1 脉诊空缺等）：盲法子代理已按验收标准标注，属良性行为。

---

## 七、结论

1. **旧"平均约 97% 盲法重合率"不成立**，需从技能验证记录中撤回或重新标注口径（含诊断+处方上下文+自我判分）。
2. **诊断泄露对旧数字的贡献 ≥ 60 个百分点**（同 16 案例：97.6% → 37.5%）；37 案全量口径旧 97.9% → 真盲法 29.9%。
3. 真盲法 30%/37.5% 是技能方法论复现能力的诚实基线；3 个 100% 与若干 30–80% 案例证明技能在"指南明确收录的经典组合"上确实可复现倪师思路，差距集中在特效奇穴触发与处方完整性。
4. **病例身份错配（21/37）是比重合率更先要处理的审计问题**：旧验证的病例文本来源待用户确认。
5. 技能改进优先级：① 症状→特效库强制反查（奇穴/耳穴必出）；② 处方结构模板化（局部+远道+俞募+未病四层）；③ 建立"仅症状输入"的盲法回归测试集（本实验 37 份症状/处方文件即可复用）。
